Polyglance Windows 便携版
========================

1. 请先完整解压 ZIP，再运行 Polyglance.exe；不要直接在压缩包预览中启动。
2. 首次运行时，所有用户配置会自动保存在当前用户的 AppData 漫游目录中。
3. 如在应用设置中开启“开机时自动启动”，Windows 会记录当前 Polyglance.exe 的完整路径。移动或删除便携版目录前，请先关闭该选项。
4. 删除便携版程序目录不会自动删除用户设置。配置保存在 %APPDATA%\Polyglance，受保护凭据保存在 %LOCALAPPDATA%\Polyglance。

如果希望使用标准安装、升级覆盖和卸载流程，请下载名称以 Windows-x64-Setup.exe 结尾的安装包。
