## macOS

Grab the latest `.dmg` from [GitHub Releases](https://github.com/ldjx7/Polyglance/releases/latest). The app is not notarized; right-click → **Open** the first time.

Sparkle auto-update is built-in.

## Windows

| File | Notes |
| --- | --- |
| `Windows-x64-Setup.exe` | Recommended per-user installer with in-place upgrades |
| `Windows-x64-Portable.zip` | Portable archive, no install |
