## macOS

前往 [GitHub Releases](https://github.com/ldjx7/Polyglance/releases/latest) 下载最新 `.dmg` 或 `.zip`。

应用未经过 Apple 公证，首次打开如遇拦截，请在 Finder 中**右键 → 打开**。

支持 Sparkle 自动更新，安装后无需手动下载新版本。

## Windows

| 文件 | 说明 |
| --- | --- |
| `Windows-x64-Setup.exe` | 推荐：当前用户级安装包，支持升级覆盖与卸载 |
| `Windows-x64-Portable.zip` | 免安装便携版，解压即用 |

## 系统要求

- **macOS**：Apple Silicon / Intel，macOS 13+
- **Windows**：Windows 10/11 x64
