## 1. 划词翻译与原位替换

在任何浏览器、编辑器或阅读界面中直接处理外文：

- **划词翻译**：鼠标划选文本，按下 `⌥D` (macOS) 或 `Alt+D` (Windows)，光标旁原地弹出流式翻译气泡，支持自动语种识别与自动复制。
- **划词翻译并替换**：选中一段文字后按下 `⌥R` (macOS) 或 `Alt+R` (Windows)，系统自动完成翻译并将目标译文直接替换原选区文字。撰写外语邮件或国际化文档时无需手动复制粘贴。

---

## 2. 截屏离线 OCR 与截图翻译

面对不可选中文本、图片或视频字幕：

- **截图翻译**：按下 `⌥S` (macOS) 或 `Alt+S` (Windows) 框选区域，系统自动进行离线字符识别并直接在原位置覆盖双语对照浮层。
- **文字识别 (OCR 工作区)**：按下 `⌥C` (macOS) 或 `Alt+O` (Windows) 框选屏幕，进入分词选择模式。单击单词或拖拽框选行即可复制文本，按 `Shift+C` 可一键复制区域全部文字。
- **本地隐私防护**：macOS 采用系统 Apple Vision 框架，Windows 采用系统 Windows Media OCR 引擎，运算 100% 在本地设备端完成，图像绝不上云。

---

## 3. 专业截图与画布标注

- 按下 `⌥A` (macOS) 或 `Alt+C` (Windows) 唤起截图工具，支持智能窗口边界吸附与自由拉框。
- 标注工具箱提供：矩形、椭圆、直线、箭头、涂鸦画笔、文本排版、局部马赛克模糊、自增数字序号标号。
- 按 `Enter` 完成截图并复制图像；按 `Esc` 退出；按方向键可按像素微调选区边界。

---

## 4. 桌面贴图置顶与恢复

将重要参考图片悬浮固定在屏幕最上层：

- **贴出剪贴板图片**：按下 `⌥W` (macOS) 或 `Alt+V` (Windows)，直接将剪贴板中的最新截图或图像贴到桌面。
- **截图贴图**：框选截图后，点击工具栏中的图钉图标固定在桌面。
- **恢复关闭的贴图**：按下 `⌥⇧W` (macOS) 或 `Alt+Shift+V` (Windows) 可按顺序恢复上一张关闭的贴图。
- **贴图交互**：鼠标滚轮缩放、双击恢复 100% 比例、按 `空格键` 呼出标注工具栏直接在贴图上编辑。

---

## 5. 像素放大镜精准取色

- 截图或取色模式下，屏幕放大镜实时显示十字准星中心像素坐标与颜色值。
- 按 `C` 键：快速复制当前像素颜色。
- 按 `Shift+C` 键：在 HEX 与 RGB 颜色代码格式间切换。

---

## 6. 智能滚动长截图

捕获长网页、聊天记录或长代码段落：

1. 框选需要滚动的区域，点击工具栏的长截图图标。
2. 匀速向下滚动鼠标滚轮。
3. 算法通过特征图像素比对自动对齐并拼接连续画面。
4. 滚动结束后确认长图，支持二次编辑与无损导出。

---

## 7. 区域屏幕录制

轻量录制教学步骤与操作演示：

- 点击工具栏录屏按钮或触发自定义录屏快捷键。
- 自由框选录制范围，支持导出为 GIF 动图或 MP4 高清视频。
- 支持同时内录系统内部声音与麦克风旁白。

---

## 8. 工具栏与截图录屏独立设置

在 **偏好设置** 中提供专门的独立配置项：

- **截图与录屏设置**：自定义录屏格式（MP4 / GIF）、帧率、系统音频内录开关、麦克风设备选择、长截图拼接灵敏度与重叠容差。
- **工具栏设置**：支持自定义工具栏尺寸缩放、位置吸附居中以及按钮显示顺序。
- **服务提供商配置**：默认内置免费 Microsoft、Google 翻译渠道与 Free AI 极速通道；亦可自由接入 DeepSeek、OpenAI 或本地 Ollama 等自定义大模型。
