## 1. 划词选区翻译

在阅读任意网页、文档或代码时，直接在屏幕原地获取流式翻译：

1. 鼠标划选屏幕待翻译文本。
2. 按下默认快捷键 `Ctrl+Shift+3`（macOS 对应 `⌃⇧3`）。
3. 屏幕即刻弹出流式翻译气泡，自动检测语种并给出译文。
4. 翻译完成后默认自动复制译文至剪贴板（可在偏好设置中自定义）。

## 2. 截屏离线 OCR 与截屏翻译

针对不可复制文本、图片、视频字幕：

- **截屏翻译**：按下 `Ctrl+Shift+4`（macOS 对应 `⌃⇧4`），框选区域后立即在屏幕原位呈现对照翻译浮层。
- **选词与复制**：按 `Ctrl+Shift+1` 截图框选后，点击工具栏中的 OCR 按钮进入选词模式。单击高亮单词即可复制，按 `Shift+C` 可一键复制全部识别文本。
- **本地隐私**：macOS 采用 Apple Vision 框架，Windows 采用 Windows Media OCR 原生引擎，全本地运算，绝不上传图像。

## 3. 截图与桌面标注

专业级桌面截图与标记工具箱：

- 按 `Ctrl+Shift+1` 唤起截图，支持智能窗口吸附与自由拉框。
- 工具箱包含：矩形、椭圆、直线、箭头、画笔、文字、马赛克、自增数字序号标号。
- 快捷操作：`Enter` 完成并复制，`Ctrl+Z` 撤销，`Ctrl+Y` / `Cmd+Shift+Z` 重做，方向键按像素微调选区。

## 4. 桌面贴图置顶

将关键图像悬浮固定在所有窗口之上：

- **创建贴图**：截图后点击工具栏图钉，或按 `Ctrl+Shift+2` 直接将剪贴板中的图片贴在桌面。
- **恢复贴图**：按 `Ctrl+Shift+5` 顺序恢复最近关闭的贴图。
- **交互**：鼠标滚轮缩放、双击恢复原始尺寸、按 `空格键` 展开标注工具栏直接在贴图上绘制。

## 5. 像素精准取色

- 截图或取色模式下，屏幕放大镜十字准星显示精准坐标与色值。
- 按 `C`：复制当前像素颜色。
- 按 `Shift+C`：切换 HEX 与 RGB 颜色格式。

## 6. 智能滚动长截图

捕获长网页、代码段落或聊天记录：

1. 截图框选滚动区域后，点击长截图按钮。
2. 匀速向下滚动鼠标滚轮。
3. 算法自动比对重叠特征像素拼接画面。
4. 滚动结束后确认长图，支持二次裁剪、标注与高清导出。

## 7. 区域屏幕录制

轻量录制演示动图与教学视频：

- 点击工具栏录屏按钮或使用自定义录屏快捷键。
- 支持自由框选录制范围，选择输出为 GIF 动图或 MP4 视频。
- 支持内录系统声音与麦克风声音。

## 8. 翻译服务配置

- **免配置公共服务**：内置 Microsoft 与 Google 翻译通道，开箱即用。
- **自定义大模型**：可在 偏好设置 → 服务设置 中接入任意兼容 OpenAI 规范的 API 端点（如 DeepSeek、OpenAI、本地 Ollama 等）。
