## 全局默认快捷键（推荐方案）

所有快捷键均可在 **偏好设置 → 快捷键** 中自由修改或解绑。

| 功能动作 | macOS 默认 | Windows 默认 | 说明 |
| --- | --- | --- | --- |
| **截图工具** | `⌥A` (`Option+A`) | `Alt+C` | 框选屏幕、标注、取色与贴图 |
| **划词翻译** | `⌥D` (`Option+D`) | `Alt+D` | 选中文本弹出原地流式翻译气泡 |
| **划词翻译并替换** | `⌥R` (`Option+R`) | `Alt+R` | 选中文本后自动翻译并直接替换原内容 |
| **截图翻译** | `⌥S` (`Option+S`) | `Alt+S` | 框选屏幕任意区域进行离线 OCR 与对照翻译 |
| **贴出剪贴板图片** | `⌥W` (`Option+W`) | `Alt+V` | 将剪贴板中的图片直接贴到屏幕最上层 |
| **恢复最近关闭的贴图** | `⌥⇧W` (`Option+Shift+W`) | `Alt+Shift+V` | 按顺序恢复上一张关闭的桌面贴图 |
| **文字识别 (OCR)** | `⌥C` (`Option+C`) | `Alt+O` | 框选区域提取纯文本，支持分词点选复制 |

## 内置快捷键方案预设

偏好设置中提供三种经典键位预设，方便快速切换：

- **推荐方案（默认）**：以 `Option` (macOS) / `Alt` (Windows) 为基础前缀，单手即可完成高频操作。
- **Snipaste 风格**：`F1` 截图、`F3` 贴图、`Shift+F3` 恢复贴图。
- **PixPin 风格**：`Ctrl+1` 截图、`Ctrl+2` 贴图、`Ctrl+Q` 划词翻译、`Alt+Q` 截图翻译、`Ctrl+3` 文字识别。

## 可选绑定动作

以下功能默认未占用全局快捷键，可在偏好设置中根据个人习惯录制绑定：

- **输入翻译 (主窗口)**：调出独立查词与多语种双栏对照主窗口
- **截图并复制**：框选区域后直接复制图片到剪贴板，跳过标注栏
- **智能滚动长截图**：一键进入滚动长图捕获模式
- **区域屏幕录制**：一键进入屏幕区域录制模式
- **读取选区（不自动翻译）**：仅抓取当前划选文字至主窗口输入框

## 截图选取与标注编辑

在进入截图状态后生效：

| 按键 / 操作 | 功能说明 |
| --- | --- |
| `Enter` | 完成截图并复制图像到剪贴板 |
| `Esc` | 取消当前选区或退出截图状态 |
| `Delete` / `Backspace` | 删除当前选中的标注元素 |
| 方向键 `↑ / ↓ / ← / →` | 移动选区 1 像素（按住 `Shift` 移动 10 像素） |
| `Cmd+Z` / `Ctrl+Z` | 撤销上一步标注 |
| `Cmd+Shift+Z` / `Ctrl+Y` | 重做已撤销的标注 |
| `C` | 像素放大镜模式下复制十字准星处色值 |
| `Shift+C` | 切换取色格式（HEX 与 RGB 互相切换） |

## 桌面贴图交互

针对固定在屏幕上的贴图窗口生效：

| 按键 / 操作 | 功能说明 |
| --- | --- |
| `空格键` | 展开或收起贴商标注工具栏 |
| 鼠标滚轮 | 无级平滑缩放贴图尺寸 |
| 双击贴图 | 快速还原至 100% 原始比例 |
| 鼠标右键 | 呼出贴图菜单（复制、保存、取色、历史记录、销毁） |
| `Esc` | 关闭当前活动贴图窗口（非标注编辑状态） |

---

## 离线 OCR 文本交互

在进入文字识别工作区后生效：

| 按键 / 操作 | 功能说明 |
| --- | --- |
| 鼠标单击 / 框选 | 选择特定单词或整行文本 |
| `Cmd+C` / `Ctrl+C` | 复制当前选中的文本 |
| `Shift+C` | 一键复制识别区域内的全部文本 |
| `Esc` | 退出 OCR 识别浮窗 |
