## 全局核心快捷键

| 功能 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| **截图工具**（截图、标注与置顶） | `Ctrl+Shift+1` | `Ctrl+Shift+1` |
| **贴出剪贴板图片** | `Ctrl+Shift+2` | `Ctrl+Shift+2` |
| **划词选区翻译** | `Ctrl+Shift+3` | `Ctrl+Shift+3` |
| **截屏翻译** | `Ctrl+Shift+4` | `Ctrl+Shift+4` |

## 可选功能（偏好设置中自由配置）

- **唤起主翻译窗口**：未预设（支持自定义）
- **智能滚动长截图**：未预设（支持自定义）
- **区域屏幕录制**：未预设（支持自定义）
- **恢复最近关闭的贴图**：未预设（支持自定义）

## 截图编辑

| 快捷键 | 功能 |
| --- | --- |
| `C` | 复制当前像素颜色 |
| `Shift+C` | 切换颜色格式 HEX / RGB |

## OCR 选词

| 快捷键 | 功能 |
| --- | --- |
| `Command+C` | 复制选中文字 |
| `Shift+C` | 复制全文 |
