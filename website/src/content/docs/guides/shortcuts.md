## 全局核心快捷键

| 功能 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| **截图工具**（截图、标注与置顶贴图） | `Ctrl+Shift+1` | `Ctrl+Shift+1` |
| **贴出剪贴板图片**（桌面贴图） | `Ctrl+Shift+2` | `Ctrl+Shift+2` |
| **划词选区翻译**（选中文本弹出气泡） | `Ctrl+Shift+3` | `Ctrl+Shift+3` |
| **截屏翻译**（框选屏幕区域识别翻译） | `Ctrl+Shift+4` | `Ctrl+Shift+4` |
| **恢复最近关闭的贴图** | `Ctrl+Shift+5` | `Ctrl+Shift+5` |

## 可选功能（偏好设置中自由配置）

- **唤起主翻译窗口**：未预设（可在 偏好设置 → 快捷键 中录制绑定）
- **智能滚动长截图**：未预设（可在 偏好设置 → 快捷键 中录制绑定）
- **区域屏幕录制**：未预设（可在 偏好设置 → 快捷键 中录制绑定）
- **仅读取选区（不自动翻译）**：未预设（可在 偏好设置 → 快捷键 中录制绑定）

## 截图选取与标注编辑

| 快捷键 | 功能说明 |
| --- | --- |
| `Enter` | 完成截图并复制图像到剪贴板 |
| `Esc` | 取消当前选区或退出截图工具 |
| `Delete` / `Backspace` | 删除当前选中的标注元素 |
| 方向键 `↑ / ↓ / ← / →` | 移动选区 1 像素（按住 `Shift` 移动 10 像素） |
| `Cmd+Z` / `Ctrl+Z` | 撤销上一步标注 |
| `Cmd+Shift+Z` / `Ctrl+Y` | 重做标注 |

## 像素取色与桌面贴图

| 交互 / 快捷键 | 功能说明 |
| --- | --- |
| `C` | 放大镜取色模式下复制当前十字准星像素颜色 |
| `Shift+C` | 切换取色格式（HEX / RGB） |
| `空格键` | 开启或退出贴图窗口的标注编辑工具栏 |
| 双击贴图 | 快速放大贴图或还原至原始比例 |
| 鼠标滚轮 | 无级缩放桌面贴图 |
| 鼠标右键 | 打开贴图右键菜单（复制、保存、取色、历史记录） |
| `Esc` | 关闭当前活动贴图窗口（非标注编辑状态） |

## 离线 OCR 选词

| 操作 / 快捷键 | 功能说明 |
| --- | --- |
| 鼠标点选 / 框选 | 选择特定文字块或词组 |
| `Cmd+C` / `Ctrl+C` | 复制选中文字 |
| `Shift+C` | 一键复制识别区域内的全部文字 |
| `Esc` | 退出 OCR 识别浮窗 |
