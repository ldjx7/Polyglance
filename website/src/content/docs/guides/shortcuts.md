---
title: 快捷键
description: 默认快捷键列表，均可在设置中自定义
---

## 翻译

| 快捷键 | 功能 |
| --- | --- |
| `Option+D` | 取词并翻译 |
| `Option+Shift+D` | 仅取词 |

## 截图与贴图

| 快捷键 | 功能 |
| --- | --- |
| `Option+1` | 高分辨率截图 |
| `Option+2` | 贴出剪贴板图片 |
| `Option+3` | 长截图 |
| `Option+4` | 区域录屏 |
| `Option+5` | 恢复最近关闭的贴图 |

## 截图编辑

| 快捷键 | 功能 |
| --- | --- |
| `C` | 复制当前像素颜色 |
| `Shift+C` | 切换颜色格式 HEX / RGB |

## OCR 选词

| 快捷键 | 功能 |
| --- | --- |
| `Command+C` | 复制选中文字 |
| `Shift+C` | 复制全文 |
