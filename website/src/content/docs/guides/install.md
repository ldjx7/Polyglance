title: 安装
description: 安装 Polyglance
---

## macOS

1. 从 [Releases](https://github.com/ldjx7/Polyglance/releases/latest) 下载最新 `.dmg`
2. 拖入「应用程序」
3. 首次打开如遇 macOS 拦截：Finder 中**右键 → 打开**
4. 授予**辅助功能**和**屏幕录制**权限（用于划词取词与截图）

## Windows

下载 `Windows-x64-Setup.exe`，双击安装即可。便携版解压即用。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 辅助功能 | 读取光标处选中的文字（模拟复制兜底） |
| 屏幕录制 | 截图、OCR、长截图 |
| 通知 | 翻译完成提示 |
