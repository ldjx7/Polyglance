## 1. 截图选区与遮罩系统交互

### 1.1 触发与全屏冻结
1. **触发源**：
   - 全局热键 `F4`（截图翻译）或 `Alt+W`（划词剪贴板翻译）；
   - 主窗口顶部快捷栏点击裁剪图标；
   - 系统托盘菜单选择截图、文字识别或截图翻译。
2. **底层动作**：
   - 触发瞬间，主窗口根据意图决定是否隐藏（截图翻译隐藏，普通截图若被遮挡则最小化）；
   - 后台通过 Win32 API 捕获多显示器虚拟屏幕的统一完整帧（跨负坐标扩展屏）：
     ```
     VirtualLeft = GetSystemMetrics(SM_XVIRTUALSCREEN);
     VirtualTop = GetSystemMetrics(SM_YVIRTUALSCREEN);
     VirtualWidth = GetSystemMetrics(SM_CXVIRTUALSCREEN);
     VirtualHeight = GetSystemMetrics(SM_CYVIRTUALSCREEN);
     ```
   - 弹出全屏置顶无边框覆盖层，位置精确设置在 `(VirtualLeft, VirtualTop)`，尺寸为 `(VirtualWidth, VirtualHeight)`，并将截帧完整作为背景渲染，使桌面产生瞬间被定格的视觉反馈。

### 1.2 候选窗口智能吸附（Candidate Snapping）
1. **探测逻辑**：
   - 当处于初始状态（未开始框选，`SelectionPhase::Ready`）时，系统监听 `MouseMove` 事件。
   - 使用 Win32 `WindowFromPoint` 与 `GetWindowRect` 探测当前光标所在的顶层窗口及子控件（排除截图遮罩窗体本身）。
2. **高亮视觉**：
   - 检测到目标矩形 `candidateRect` 时，在其四周绘制 2px 宽度的品牌强调色边框（`#0A84FF`，带 15% 内部半透明填充 `#1A0A84FF`）。
   - 在候选外框的左上方浮现圆角黑色半透明徽标，内部展示该窗口的物理宽高（例如 `1280 × 720`，字号 11px，文字颜色 `#FFFFFF`）。
3. **一键选定**：
   - 用户在候选状态下直接单击左键，系统跳过拖拽划选过程，直接将 `candidateRect` 确立为已选定矩形，进入选区确认态。

### 1.3 放大镜与取色器（Magnifier & Color Picker）
1. **位置跟随与防遮挡**：
   - 放大镜在 `Ready` 状态以及拖拽划选 `DraggingNew` 过程中常驻显示。
   - 相对光标位置偏移固定为 `(X + 16px, Y + 16px)`。
   - 当光标接近屏幕右边缘或底边缘时（距离边界小于放大镜自身宽高 + 16px），放大镜自动翻转至光标左侧 `(X - Width - 16px)` 或上方 `(Y - Height - 16px)`，保证放大镜永不超出工作区。
2. **视图与网格**：
   - 放大镜尺寸为 `120 × 120 px`（圆角矩形，CornerRadius 8px，白底 1px 浅灰边框，带深度阴影）。
   - 内部将光标中心点周围 `15 × 15` 像素放大 8 倍呈现，每个像素呈现为清晰方格，网格线颜色为细微白线（透明度 20%）。
   - 中心目标像素绘制醒目的高亮准星与十字交叉线。
3. **色彩与坐标数据展示**：
   - 放大镜底部信息条（高度 30px，背景 `#1E293B`，文字颜色 `#FFFFFF`）：
     - 第一行：当前屏幕坐标 `X: {x}, Y: {y}`；
     - 第二行：中心像素色值 `RGB({r}, {g}, {b})` 及十六进制 `#RRGGBB`。
4. **快捷取色操作**：
   - 按下键盘 `C` 键：将当前十六进制颜色码直接复制到系统剪贴板（如 `#FFFFFF`），并有极短的轻微蜂鸣音或浮现已复制气泡；
   - 按下键盘 `Shift` 键：在十六进制 HEX 与十进制 RGB 格式之间切换。

### 1.4 鼠标划选与遮罩挖空
1. **状态流转**：
   - 鼠标左键按下时，记录起始点 `_dragStart = Point(e.x, e.y)`，状态切为 `SelectionPhase::DraggingNew`。
   - 立即隐藏窗口吸附高亮与主工具栏，保持放大镜处于活动状态以协助用户对齐边界像素。
2. **遮罩挖空数学与渲染**：
   - 覆盖层采用反向剪裁（Clip-Out / Exclude）机制。
   - 屏幕总矩形为 `R_screen`，当前选区矩形为 `R_sel = Rect::from_points(_dragStart, currentPoint)`。
   - 遮罩层仅在集合 `R_screen \ R_sel` 的差集区域填充 `#000000`（透明度 0.38）；
   - **选区矩形 `R_sel` 内部填充透明度为 0（完全挖空透光）**，无任何遮罩色，完整保留 100% 原始屏幕亮度。
3. **选区边框与四角把手**：
   - 选区边缘绘制 1px 细线边框（外发光投影，避免与纯白/纯黑画面混色）；
   - 拖拽中在四角绘制 `6 × 6 px` 白色实心正方形手柄。

### 1.5 选区调节手势与控制手柄（8-Handle Resizing & Moving）
当用户释放鼠标左键，若选区宽高大于 6px，状态机进入 `SelectionPhase::Selected`。此时屏幕不退出，进入精细调校模式：

1. **8 个控制点位置布局**：
   - 四角：左上（TopLeft）、右上（TopRight）、左下（BottomLeft）、右下（BottomRight）；
   - 四边中点：顶中（Top）、底中（Bottom）、左中（Left）、右中（Right）；
   - 每个把手为 `8 × 8 px` 白色填充、带 1px 深色边框的正方形控制块，居中定位在对应的边缘中点或顶点上。
2. **悬停光标映射规则（Hit Testing）**：
   - 命中手柄的检测容差半径为 6px。
   - 鼠标悬停到把手时，光标根据几何方位改变：
     - TopLeft、BottomRight -> `SizeNWSE`（斜向双箭头 ↖↘）
     - TopRight、BottomLeft -> `SizeNESW`（斜向双箭头 ↗↙）
     - Left、Right -> `SizeWE`（水平双向双箭头 ↔）
     - Top、Bottom -> `SizeNS`（垂直双向双箭头 ↕）
   - 鼠标位于选区内部（非手柄区域）：
     - 当未激活标注工具时 -> `SizeAll`（十字平移光标 ✢）；
     - 当激活标注工具时 -> 对应工具专有光标（画笔、十字准星、文字光标等）。
   - 鼠标位于选区外部 -> `Cross`（十字光标，表示外扩拉伸）。
3. **8 向拉伸调节（Resizing）**：
   - 鼠标在手柄上按下左键并移动，状态切换为 `SelectionPhase::Resizing`。
   - 拖拽手柄只改变对应的边或顶点坐标，选区其余边保持锚定。例如拖动右边把手仅更新 `R_sel.right`，顶边、底边和左边完全不动。
4. **整体平移（Moving）**：
   - 鼠标在选区内部按下左键并移动，状态切换为 `SelectionPhase::Moving`。
   - 记录拖动起止增量 `(dx, dy)`，将整个选区在屏幕上移动，尺寸 `(width, height)` 严格保持不变。
   - 移动边界限制：自动限制在桌面虚拟屏幕边界之内，防止移出可视范围。
5. **选区单向外扩（Expanding）**：
   - 鼠标在选区外部按住拖拽时，状态切换为 `SelectionPhase::Expanding`。
   - 选区朝光标移动的方向单独延展拉伸，方便用户补选被遗漏的屏幕元素。

### 1.6 快捷手势与退出机制
1. **极速双击复制（Fast Double-Click Copy）**：
   - 选区确立后，在选区内部双击鼠标左键（两次点击间隔小于系统双击时间，通常 500ms 内）：
   - 立即将当前选区（含已画的所有标注图元）合成到位图，写入系统剪贴板，并安全退出截图。
2. **右键逐级回退机制（Strict Hierarchical Cancellation）**：
   - 用户单击鼠标右键时，系统按照以下严格优先级执行单步回退：
     - **第 1 级**：若当前有被鼠标二次选中的标注图元，取消选中该图元（恢复无选中状态）；
     - **第 2 级**：若当前激活了标注工具（画笔、箭头、文字等），退出标注工具，收起二级属性栏，光标恢复为平移光标；
     - **第 3 级**：若当前存在已确定的选区矩形，清除该选区，重置为全屏遮罩状态，放大镜与窗口候选吸附重新激活；
     - **第 4 级**：若当前已处于初始全屏遮罩状态，彻底关闭截图窗口，恢复正常桌面。
   - 这种设计确保用户操作失误时随时右键撤退，绝不发生误退。

## 2. 两级工具栏与标注系统交互

### 2.1 智能跟随与自主拖拽定位算法
1. **自动停靠定位公式**：
   - 设当前选区为 `selRect`，桌面工作区为 `screen`。
   - 一级主工具栏宽度 `TB1_W`（约 632px），高度 `TB1_H`（40px）；二级属性栏高度 `TB2_H`（32px），两栏间距 `GAP = 6px`。
   - 纵向定位 `Y` 计算：
     ```
     preferredY = selRect.bottom + 8px;
     totalHeight = TB1_H + GAP + TB2_H;
     if (preferredY + totalHeight > screen.bottom - 8px) {
         if (selRect.top - totalHeight - 8px >= screen.top + 8px) {
             finalY = selRect.top - totalHeight - 8px; // 向上翻转
         } else {
             finalY = max(screen.top + 8px, screen.bottom - totalHeight - 8px);
         }
     } else {
         finalY = preferredY;
     }
     ```
   - 横向定位 `X` 计算：
     ```
     preferredX = selRect.right - TB1_W; // 右对齐
     finalX = clamp(preferredX, screen.left + 8px, screen.right - TB1_W - 8px);
     ```
2. **工具栏自主拖拽移动**：
   - 工具栏最左侧区域设计有轻微点状防滑把手。
   - 鼠标在工具栏空白处或把手上按住左键拖动时，光标变为 `SizeAll`，工具栏整体跟随鼠标平移。
   - 拖拽后记录 `_isToolbarManuallyMoved = true`，后续微调选区时不再强制重置工具栏位置。

### 2.3 二级属性子工具栏详细规格
点击 1~8 项标注工具时，在主工具栏外侧平滑展开二级工具栏（高度 32px，圆角 16px，白底投影）：

1. **线宽与粗细调节组（PanelStrokeSizes）**：
   - 界面呈现一个带实心小圆点和当前数值的药丸按钮（如 `● 4`）。
   - 点击该按钮弹出微型 Popup，内含横向平滑滑动条（Slider，范围 1~50px，步长 1），右侧伴随文本显示 `4 px`。
   - **滚轮全局调节**：鼠标光标悬停在二级工具栏任意位置滚动滚轮，线宽直接自增或自减 1px，无需手动点击滑块。
2. **标准调色盘（PanelColorPalette）**：
   - 排列 8 种高对比度色块单选按钮（直径 20px，内圆 14px，间距 3px）：
     - 珊瑚红：`#EF4444`
     - 活力橙：`#F97316`
     - 柠檬黄：`#FACC15`
     - 薄荷绿：`#10B981`
     - 宝石蓝：`#3B82F6`
     - 优雅紫：`#8B5CF6`
     - 炭黑板岩：`#1F2937`
     - 纯白（带极细外圈）：`#FFFFFF`
   - 选中的色块外围呈现同心圆环圈（粗 1.8px，透明度 90%）。
3. **箭头与线条样式下拉组（PanelLineControls）**：
   - 箭头样式下拉框：支持 9 种几何图符绘制（细单向、细双向、粗单向、粗双向、空心左小右大箭头、实心左小右大箭头、双向T型端点线、单向实心三角箭头、双向实心三角箭头）。
   - 线条虚实下拉框：实线（Solid）、长虚线（Dash `4 2`）、点线（Dot `1 2`）、点划线（Dash-Dot `6 2 1 2`）。
4. **矩形/椭圆属性组（PanelRectControls）**：
   - 填充复选框（Checkbox）：勾选后图形变为对应调色盘颜色的半透明填充（透明度 25%）或实心填充。
   - 边框虚实下拉框：实线、长虚线、点线、点划线。
5. **文字属性组（PanelTextControls）**：
   - 字体族下拉框（FontFamily）：支持系统默认、微软雅黑、宋体、黑体、楷体、Segoe UI、Arial、Georgia、Courier New、Times New Roman。
   - 字号下拉框（FontSize）：预设 12pt、14pt、16pt（默认）、18pt、20pt、24pt、28pt、32pt、36pt、48pt、64pt、72pt。
   - 样式切换按钮：加粗（B）、斜体（I）、文字背景白底边框（T，解决复杂背景下文字辨识度问题）。
6. **序号属性组（PanelNumberControls）**：
   - 实心气泡按钮：彩色背景，白色加粗数字。
   - 空心气泡按钮：彩色外边框，彩色加粗数字，背景透明。
7. **马赛克属性组（PanelMosaicControls）**：
   - 下拉选项：涂抹·像素化、涂抹·高斯模糊、矩形·像素化、矩形·高斯模糊。

### 2.4 标注图元数据模型与二次编辑交互
标注系统采用图元对象列表模型，而非直接把笔画刻死在位图上：

1. **图元抽象类型**：
   - `PenItem`: 点序列 `Vec<Point>`、线宽、颜色。
   - `LineItem`: 起点、终点、线宽、颜色、虚实样式。
   - `ArrowItem`: 起点、终点、线宽、颜色、箭头头部样式。
   - `RectItem`: 矩形区域、线宽、颜色、虚实样式、是否填充。
   - `EllipseItem`: 外接矩形、线宽、颜色、虚实样式、是否填充。
   - `TextItem`: 放置点、文本内容、字体、字号、颜色、粗斜体、外框背景。
   - `NumberBadgeItem`: 中心坐标、自增序号数字（1, 2, 3...）、半径、实心/空心。
   - `MosaicItem`: 涂抹路径/矩形选区、块大小（BlockSize）、算法（像素网格或模糊）。
2. **拾取与选中框（Selection Box）**：
   - 在已绘制图元上单击鼠标左键，该图元被拾取（`_selectedAnnotationElement = Some(item)`）。
   - 选中的图元四周绘制蓝色虚线框，且端点和四角绘制控制手柄（半径 4px）。
3. **控制手柄交互**：
   - 拖拽端点手柄：改变线条或箭头的起止位置、倾斜角度与长度；
   - 拖拽边角手柄：等比例或自由缩放矩形、椭圆、文本框尺寸；
   - 拖拽图元本体：平移整条标注的位置；
   - 双击文本框：激活光标，用户可直接追加、修改文本；
   - 按下 `Delete` 键：删除该图元，推入撤销栈。
4. **合成导出机制（Compositing）**：
   - 在用户点击复制、贴图、保存、OCR 或翻译的瞬间，后台创建离屏渲染缓冲区：
   - 先将底层原始截图像素绘制到底层；
   - 再按绘制先后次序（Z-Order）依次绘制所有图元对象；
   - 最终提取合并后的纯净 RGBA 像素数据派发给相应业务模块。

## 3. 贴图系统交互（PinWindow）

### 3.1 原位像素级绝对坐标对齐
1. **绝对坐标保持**：
   - 贴图窗口创建时，入参包含选区在虚拟多屏中的屏幕物理绝对坐标 `(rect.x, rect.y)` 与像素宽高 `(rect.width, rect.height)`。
   - 贴图窗口通过底层 `SetWindowPos` 直接将坐标设定为 `(rect.x, rect.y)`。
   - 用户点击贴图按钮后，截图遮罩淡出，贴图窗口同步就绪，视觉上被框选的图片原地纹丝不动地保留在屏幕最前端，没有任何居中弹跳、偏移抖动或缩放闪烁。

### 3.2 纯净无框浮层视觉规范
1. **彻底移除系统装饰**：
   - 彻底剥除 Windows 原生边框与标题栏样式：
     `Style &= ~(WS_CAPTION | WS_THICKFRAME | WS_MINIMIZEBOX | WS_MAXIMIZEBOX); Style |= WS_POPUP;`
   - 扩展样式加入工具窗口与置顶：
     `ExStyle |= WS_EX_TOOLWINDOW | WS_EX_TOPMOST;`
2. **微边缘与阴影**：
   - 贴图背景完全透明，内容填充合成图像。
   - 四周保留 1px 微弱半透明黑色边框（`#20000000`），避免在白色文档或浅色网页背景上发生边界融合；
   - 边缘外附带 8px 柔和微阴影（Blur 8, ShadowDepth 2, Opacity 0.15）。

### 3.3 鼠标手势与动态控制
1. **鼠标拖拽平移（Drag & Move）**：
   - 鼠标左键在贴图内部任意位置按下并移动时，触发窗口平移。
   - 底层实现机制：向窗口过程发送 `ReleaseCapture()` 与 `SendMessage(hwnd, WM_NCLBUTTONDOWN, HTCAPTION, 0)`，由 Windows 原生窗口管理器接管平滑拖动，保证低延迟无拖影。
2. **鼠标滚轮缩放（Zooming In / Out）**：
   - 滚轮向上滚动：放大（每次步长系数为 `1.1`，上限放大至原图的 1000%）；
   - 滚轮向下滚动：缩小（每次步长系数为 `1.0 / 1.1`，下限缩小至原图的 20%）；
   - **光标锚点保持算法**：缩放时必须保持鼠标指针下所指的图像特征点位置在屏幕绝对坐标上不变，根据光标在窗口内的比例偏移动态修正窗口的 `(Left, Top)` 坐标。
   - **缩放比例徽标（Zoom Badge）**：
     - 滚动发生时，贴图正中心浮现一个半透明黑色圆角徽标（尺寸约 `60 × 26 px`，背景 `#B0000000`，圆角 6px，文字颜色纯白，字号 12px 加粗）；
     - 显示当前缩放比例，例如 `125%` 或 `80%`；
     - 用户停止滚动鼠标后，计时器延时 800ms，该徽标平滑淡出。
3. **透明度调节（Opacity Handlers）**：
   - 用户按住键盘 `Ctrl` 键同时滚动滚轮：
     - 滚轮向上：不透明度增加 5%（上限 100%）；
     - 滚轮向下：不透明度降低 5%（下限 20%）；
   - 窗口即时调用 `SetLayeredWindowAttributes` 或调整 Slint 窗口不透明度。
4. **双击极速关闭**：
   - 鼠标左键快速双击贴图任意位置，立即触发关闭与隐藏。

### 3.4 右键上下文菜单与全功能集成
在贴图上单击右键，弹出原生样式的上下文菜单，提供完整扩展操作：
1. **复制图片**：将贴图位图放入剪贴板；
2. **保存图片**：弹出文件保存对话框，支持 PNG、JPG、BMP 导出；
3. **二次涂鸦标注**：在贴图上方再次拉出两级标注工具栏，允许对已贴在屏幕上的图层补充圈画涂鸦并实时保存；
4. **文字识别 (OCR)**：对贴图启动 OCR 文本解析，在贴图表面将文字以半透明背景分块高亮，支持鼠标直接划词选中、双击选中单句并自动复制或翻译；
5. **锁定／解锁贴图**：
   - 锁定状态下，贴图忽略鼠标拖拽手势，防止用户在阅读打字时误触移动；
   - 再次右键可选择解锁；
6. **置顶切换**：切换窗口是否具备 `HWND_TOPMOST` 属性；
7. **恢复最近关闭的贴图**：从历史会话中复原上一次关闭的贴图；
8. **销毁贴图及历史**：从内存与本地持久化历史中彻底删除该贴图记录；
9. **销毁全部贴图**：一键关闭并清空所有激活的贴图窗口。

2. **多服务商并发卡片瀑布流**：
   - 原文输入后触发翻译，下方各服务商译文卡片各自独立显示骨架屏（Shimmer）或加载旋转菊花。
   - 哪家服务商先返回结果，哪家卡片率先渲染完成，杜绝慢速服务商阻塞整体界面的情况。

## 5. 偏好设置独立窗口交互规范（SettingsWindow）

### 5.1 独立生命周期与多板块导航
1. **独立顶层窗体**：
   - 设置窗口是一个完全独立的桌面窗体（`SettingsWindow`），非主窗口内嵌标签页。
   - 主窗口隐藏至托盘或执行截图时，设置窗口依然独立保持在桌面上，互不影响。
2. **视觉与尺寸**：
   - 尺寸：宽度 900px，高度 600px（最小宽度 760px，最小高度 500px）。
   - 采用 Win11 亚克力 / 云母风格，左侧为 190px 固定侧边栏，右侧为带滚动条的卡片列表。
3. **左侧 9 大导航条目**：
   - `翻译设置`：配置官方 Free AI、Google、Microsoft、DeepL、OpenAI 接口与密钥。
   - `收藏夹`：浏览、导出和检索收藏词汇。
   - `历史记录`：本地离线翻译历史的分页浏览、单项删除与全局清空。
   - `OCR 设置`：系统 OCR 与本地 ONNX OCR 模型路径、离线运行时管理。
   - `通用设置`：开机自启动、关闭时最小化至托盘、数据目录迁移与一键重置。
   - `快捷键`：全局热键可视化录制。
   - `截图与录屏`：鼠标穿透置顶参数、截图工具栏显示控制、录屏帧率与码率。
   - `工具栏`：一级工具栏 19 个按钮的自定义勾选与排序。
   - `关于`：版本号展示、更新检查、开源许可证。

### 5.2 快捷键录制控件（ShortcutRecorderControl）
快捷键必须采用可视化按键捕获控件，杜绝纯手工输入文本产生歧义：
1. **初始状态**：显示当前已绑定的热键药丸按钮（如 `F4` 或 `Alt + W`），右侧配有清空小叉号 `×`；
2. **进入录制**：用户单击该药丸，按钮边框呈现蓝色呼吸高亮，内部文字变为 `请按下快捷键...`；
3. **按键捕获与拦截**：
   - 监听底层 `KeyDown` 与 `SysKeyDown` 消息；
   - 自动识别修饰键状态（`Ctrl`、`Shift`、`Alt`、`Win`）；
   - 配合实体键（字母、数字、功能键 F1~F12、方向键、Tab、Space 等）；
4. **录制完成**：用户完全松开按键后，自动将按键组合规范化保存（例如 `Ctrl + Shift + F4`），并即时向系统注册全局热键；若该热键已被其他应用占用，控件即时变红并弹出冲突告警提示。

### 5.3 存储路径管理交互
- 数据存储目录卡片展示当前正在使用的完整物理路径（只读或可编辑文本框）；
- 附带三枚标准操作按钮：
  - **打开目录**：直接调用 Windows Explorer 打开定位到该文件夹；
  - **更改目录**：弹出系统文件夹选取对话框；
  - **恢复默认**：将路径重置回 `%APPDATA%\Polyglance`。
