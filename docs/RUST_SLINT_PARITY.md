# Windows WPF 与 Rust + Slint 功能对照

更新：2026-09-29。该表以当前仓库的 Windows 客户端与 Rust 预览版为准。`初版`表示存在入口或实现，但未完成完整的行为验收；`核心完成`表示纯 Rust 逻辑有测试，不代表界面功能完成。正式替换 WPF 前，每项均需在同一台 Windows 机器上执行相同操作并记录结果。

| 用户流程 | Rust + Slint 现状 | 仍需完成或验证 |
|---|---|---|
| 主窗口输入多行文本 | 已实现多行输入 | 中文输入法、候选框位置、长文本和键盘导航 |
| 免费翻译渠道 | 已接入共享服务商逻辑 | 网络错误、流式体验和旧版结果一致性 |
| Google 与 Microsoft 翻译 | 已接入共享服务商逻辑 | 限流、失败重试和结果展示 |
| 自定义 AI 服务商 | 单个 OpenAI 兼容入口初版 | 多配置、模型参数、DeepSeek/Claude 等既有设置 |
| 语言选择与互换 | 初版 | 全部旧版语言和自动检测行为 |
| 并发翻译与取消 | 请求归属状态有测试 | 真实网络请求取消与窗口关闭后的清理 |
| 结果复制 | 初版 | 各服务卡片交互和格式 |
| 翻译历史 | Windows JSON 格式兼容测试、界面初版 | 搜索、筛选、配置目录和多进程冲突 |
| 设置与凭据 | Windows DPAPI 保存、旧凭据读取初版 | 所有旧配置迁移、失败回退、Linux 凭据存储 |
| 全局划词翻译 | 托盘入口通过记录前台窗口、模拟复制并用 OLE 恢复剪贴板获取选中文本 | UI Automation 读取、全局快捷键、气泡定位、焦点恢复及真实应用兼容性验收 |
| 原位替换 | 未接入 | 无障碍输入与撤销行为 |
| 跨屏区域框选 | Win32 透明遮罩初版 | 真实多屏混合 DPI、热插拔、焦点和取消 |
| 截图、OCR 与截图翻译 | 三种托盘和快捷键入口已分流：截图生成贴图，OCR 显示识别文字，截图翻译继续调用翻译服务；Windows 系统 OCR 和 PP-OCR 入口，真实 ONNX 推理通过 | 选区工具栏、标注、结果编辑和真实桌面中的三种操作验收 |
| 多二维码识别 | 未接入 | 定位、并发识别与 Wi-Fi/名片解析 |
| 矩形、椭圆、箭头、文字、笔迹、马赛克标注 | 纯 Rust 核心和 Win32 截图遮罩的基础绘制、撤销重做、图片合成已接入 | 文字输入编辑、图元二次编辑、完整属性栏和正式版逐项交互验收 |
| 取色器 | Win32 遮罩内有放大镜和 HEX/RGB 色值复制初版 | 多屏混合 DPI、边缘定位和色值一致性 |
| 自动滚动长截图 | 手动滚动拼接初版 | 自动滚动、预览、二次标注、失败恢复 |
| 最近截图贴图 | Windows 使用独立 Win32 置顶窗口，可拖动、缩放、调节透明度；托盘可统一显示、隐藏和关闭 | 旋转、原生贴图鼠标穿透、窗口焦点及正式版交互验收 |
| 剪贴板图片贴图 | 托盘入口可贴出图片 | 剪贴板文本贴图、格式兼容、去重和快捷键 |
| 贴图历史与恢复 | Rust 预览版独立保存 PNG 历史目录；可从托盘打开目录、恢复最近关闭的贴图 | 正式版存档及会话格式兼容、历史界面、位置与状态恢复 |
| 区域 MP4 录屏 | GDI 抓帧、Media Foundation 编码初版；合成帧编码测试通过 | 真实屏幕录制、掉帧、硬件编码、长时间运行 |
| GIF、系统音频、麦克风 | 未接入 | 编码、混音、同步和权限 |
| 录屏预览及诊断 | 未接入 | 播放、进度、导出和故障定位 |
| 托盘常驻与窗口生命周期 | Slint 系统托盘初版；首次启动只驻留后台，第二次启动唤起已有翻译窗；Windows 图形会话已验证首次无主窗和再次唤窗 | 托盘右键菜单、退出行为和高 DPI 图标仍需逐项验收 |
| 全局快捷键 | Windows 注册 Alt+C 截图、Alt+S 截图翻译、Alt+O 文字识别、Alt+T 输入翻译；冲突会显示在状态栏 | 热键触发、可修改配置、其他正式版快捷键和输入法冲突 |
| 开机自启动 | 设置页读写 Rust 预览版独立的当前用户启动项，不覆盖 WPF 启动项 | 真实 Windows 登录流程及安装目录变化后的注册项维护 |
| 自动更新与回退 | 托盘可检查 GitHub Releases 中更高版本且具有 Rust 预览版安装包的发布项 | 应用内下载、安装、迁移和失败回退；没有 Rust 发布包时仅提示未发现更高版本 |
| 模型安装 | 本地文件复制、SHA-256 校验和 PP-OCR 使用初版 | 下载、版本、损坏修复、取消、离线翻译模型 |
| Linux 桌面 | Slint 界面和共享逻辑可编译设计 | 目标发行版构建、X11/Wayland 捕获与窗口、Portal 和录屏 |

当前 Rust 安装包和便携包属于独立预览轨道，不应覆盖现有 WPF 安装。体积与本次验证记录见 [重构方案](RUST_SLINT_REFACTOR_PLAN.md)。
