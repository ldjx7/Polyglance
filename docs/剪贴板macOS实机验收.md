| [超像素上限图片](../crates/clipboard-core/tests/fixtures/over-pixel-limit.png) | 有效 PNG，4001 × 4000 像素；复制后不应保存到历史。仅包含测试像素 |
| [像素边界图片](../crates/clipboard-core/tests/fixtures/at-pixel-limit.png) | 4000 × 4000 像素，供 Rust 边界回归；从原生应用复制时还受其剪贴板编码后的 16 MB 载荷限制 |
| 材料包中的 dist/clipboard-fixture-500/ 和 dist/clipboard-fixture-10000/ | 各含一个完整合成备份，分别用于 500 条和 10000 条的 GUI 测试；文字、富文本、名称、标签、来源和固定项均为测试数据 |

从设置 > 通用开启剪贴板历史，开关修改立即生效；未启用的历史窗口也可点击前往通用设置。容量、排除规则等详细选项在管理窗口的齿轮中；快速浮窗点击管理历史或按 Command+M 进入。呼出快捷键和粘贴下一条快捷键在现有偏好设置中配置，初始未分配。先只启用历史记录，通知、循环选择和 OCR 索引按对应项目逐项开启。
