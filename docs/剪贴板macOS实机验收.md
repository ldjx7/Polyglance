# 剪贴板 macOS 实机验收

本表用于将已通过的自动测试落实到真实 Mac 的权限、窗口和跨应用行为。当前交互项目均为待实测，只有实际执行后才能改为通过。公共 Rust 性能基线另见 [剪贴板性能基线.md](剪贴板性能基线.md)。

## 1. 开发包与测试环境

- 分支：`feat/clipboard-history`。
- 开发包：在该分支最近一次成功的 [Clipboard History CI](https://github.com/ldjx7/Polyglance/actions/workflows/clipboard-history-ci.yml) 中下载 `Polyglance-Clipboard-macOS-Dev`，解压得到 `Polyglance Dev.app`。构建使用 ad-hoc 开发签名。
- 验收材料：同次 CI 的 `Clipboard-Acceptance-Materials`，或本仓库 `docs/fixtures/clipboard/` 和 `crates/clipboard-core/tests/fixtures/`。
- 开发版标识为 `io.polyglance.macos.dev`，历史保存在用户 Application Support 下对应的 `ClipboardHistory` 目录。首次安装项目使用未运行过开发版的测试账号；已有开发版历史先通过数据菜单备份。
- 每轮记录开发包对应的提交 SHA、系统版本、芯片、屏幕配置和输入法。主流程先在窗口模式执行，再补全屏和多屏。
- 测试期间只复制合成样本；密码管理器项目使用新建的测试条目，内容为 `POLYGLANCE_TEST_NOT_A_PASSWORD`。

## 2. 样本和入口

| 材料 | 用法 |
|---|---|
| [sample.txt](fixtures/clipboard/sample.txt) | 用 TextEdit 打开，分别复制全文、队列三行、单个色值和排除规则样本 |
| [rich-text.html](fixtures/clipboard/rich-text.html) | 用 Safari 打开；复制框内富文本；截图下方黑白文字用于 OCR |

| [超像素上限图片](../crates/clipboard-core/tests/fixtures/over-pixel-limit.png) | 有效 PNG，4001 × 4000 像素；复制后不应保存到历史。仅包含测试像素 |
| [像素边界图片](../crates/clipboard-core/tests/fixtures/at-pixel-limit.png) | 4000 × 4000 像素，供 Rust 边界回归；从原生应用复制时还受其剪贴板编码后的 16 MB 载荷限制 |

从菜单栏打开剪贴板历史，通过齿轮开启保存；呼出快捷键和粘贴下一条快捷键在现有偏好设置中配置，初始未分配。先只启用历史记录，通知、循环选择和 OCR 索引按对应项目逐项开启。

## 3. 核心使用流程

以下各行按步骤顺序执行。结果填写通过、失败、阻塞或不适用，并附缺陷编号；未执行时保留待实测。

| 编号 | 操作 | 预期结果 | 结果 |
|---|---|---|---|
| A01 | 在首次安装账号打开开发版；开启前复制一段文本，再开启保存 | 默认关闭；开启前内容不会补录 | 待实测 |
| A02 | 开启后复制 sample.txt 全文；暂停后复制另一段；恢复后再复制新内容 | 只记录开启时的新复制；暂停期间已有历史可查阅；恢复不补录暂停内容 | 待实测 |
| A03 | 复制同一段两次，给条目加名称、标签和固定；重启开发版 | 去重后只有一条，顺序更新；内容和元数据在重启后保留 | 待实测 |
| A04 | 搜索中文、英文和不存在的词；组合类型、来源和标签筛选 | 结果正确；无匹配显示空列表；清空筛选后可继续选择和复制 | 待实测 |
| A05 | 将 Safari 样本复制到历史，再普通粘贴到 TextEdit 的富文本窗口；随后纯文本粘贴 | 普通粘贴保留支持的格式；纯文本粘贴保留文字并移除样本的富文本格式 | 待实测 |
| A06 | 固定富文本并分配可用字母键；编辑时原样保存，再次复制到 TextEdit | HTML/RTF 被移除；名称、标签、固定和绑定保留；原文不变 | 待实测 |
| A07 | Finder 同时复制样本文件甲、乙，再从历史粘贴到新建的空文件夹 | 两个文件都能重放；历史显示文件或多项，保留系统提供的项目顺序 | 待实测 |
| A08 | 移动测试文件甲的副本，再尝试重放含该文件的历史 | 明确提示文件缺失；失败操作不改写当时的系统剪贴板 | 待实测 |

## 4. 键盘、焦点和权限

| 编号 | 操作 | 预期结果 | 结果 |
|---|---|---|---|
| K01 | 从 TextEdit 呼出历史，在搜索框输入中文并用 Enter 确认候选 | 候选确认只完成输入，不误复制；输入完成后上下键和 Enter 可正常操作 | 待实测 |
| K02 | 选择历史后按 Esc；从另一应用重新呼出；再完成正常复制 | Esc 不改写剪贴板；再次呼出可正常选择，目标应用与本次呼出对应 | 待实测 |
| K03 | 未授权辅助功能时尝试自动粘贴，再按系统流程授权并重试 | 未授权时有明确反馈；授权后可粘贴到原目标；普通复制无需此权限 | 待实测 |
| K04 | 自动粘贴等待期间切换目标应用或进行外部复制 | 旧操作取消，不覆盖后来复制的内容，不误贴到新应用 | 待实测 |
| K05 | 在外接屏和全屏应用中呼出，输入、选择并退出 | 窗口位置可见；键盘输入、焦点恢复和复制行为正常 | 待实测 |
| K06 | 测试 Command+数字及固定字母键；开启循环选择，重复呼出后松开修饰键；再测试 Esc 中止 | 选中当前列表或指定固定条目；松键只确认一次；Esc、鼠标或失焦可中止 | 待实测 |
| K07 | 分别复制队列 A、B、C，多选加入队列并逐次粘贴；中途外部复制或切换应用 | 按列表顺序逐条发送；每次只发送一条；目标或剪贴板变化时停止队列 | 待实测 |

## 5. 图片、OCR 和采集边界

| 编号 | 操作 | 预期结果 | 结果 |
|---|---|---|---|
| I01 | 截取 HTML 样本的黑白文字，保存到历史，再执行贴图、识别文字和主动翻译 | 贴图使用原图；OCR 可识别关键字；只有点击翻译才调用翻译功能 | 待实测 |
| I02 | OCR 显示识别中时关闭历史并立即重开，等待旧识别结束 | 旧任务不弹出文字窗口、不显示旧错误；重开后能正常发起新识别 | 待实测 |
| I03 | OCR 识别中切换到其他条目，再切回原条目；另测清空或导入 | 旧结果不影响新选择；清空或恢复后不出现旧任务的弹窗 | 待实测 |
| I04 | 开启 OCR 搜索索引，搜索截图中的 CLIPBOARD；关闭索引，重启再搜索 | 逐张建立本机索引；关闭后停止新索引任务，已有结果保留 | 待实测 |
| I05 | 复制超像素上限 PNG，再复制普通小截图 | 超限内容不入库；原历史保留；后续普通截图仍能记录 | 待实测 |
| I06 | 连续快速复制不同短文本，再做一次截图后的划词翻译和历史重放 | 应用保持响应；临时复制与重放不产生伪记录；记录实际采样数量，当前 200 ms 轮询不保证捕获全部快速变化 | 待实测 |

I02、I03 必须实际观察到识别中再操作；图片过小导致识别已完成时，记录未满足前提并换用更复杂的测试截图。CI 中另有可控延迟的确定性回归。

|---|---|---|---|

| D03 | 开启忽略下一次复制，先做划词操作，再连续复制两个不同样本 | 内部复制不消耗状态；仅第一次外部非空复制被忽略，第二次恢复记录 | 待实测 |
| D04 | 建立带名称、标签、固定键和 OCR 的样本历史，导出后分别测试合并和替换 | 按界面说明恢复；元数据及引用正确；合并保留现有非空名称，固定键冲突保留现有绑定 | 待实测 |

| D06 | 预览清理数量，默认清理；再显式选择包含收藏并确认 | 默认保留收藏；包含收藏时才删除；数量和内容大小与操作一致 | 待实测 |
| D07 | 开启、拒绝和重新允许通知；连续复制测试样本 | 通知权限反馈正确；通知不含原文；连续事件限制提醒频率 | 待实测 |
| D08 | 在系统快捷指令搜索 Polyglance，依次测试八个动作，并在主应用退出后运行 | 动作可发现；读取返回完整文字，复制保留格式；清空默认保留收藏；冷启动仍可运行 | 待实测 |

## 7. 性能与长时间运行记录

核心基线命令见性能文档。GUI 性能用实际机器单独测量：

| 场景 | 应记录的数据 | 状态 |
|---|---|---|
| 500 条与 10000 条历史 | 呼出窗口、首次展示、输入搜索词到结果出现的耗时；至少重复 10 次 | 待实测 |
| 连续复制文本和大截图 | CPU、活动监视器内存、最大图片尺寸、复制次数、实际记录数 | 待实测 |
| 开关后台 OCR | 相同截图数量下的完成时间、CPU 和内存变化；关闭后的任务结束情况 | 待实测 |
| 空闲与休眠恢复 | 保存开启后空闲 30 分钟，记录 CPU、能耗和内存；睡眠唤醒后再复制 | 待实测 |
| 数据库故障恢复 | 在隔离测试账号用开发版数据库副本测试磁盘和权限故障，核对报错与恢复 | 待实测 |

核心基线数据库由程序临时创建并删除。GUI 测试使用材料包中的合成备份：先备份开发版已有历史，将最大条数调到 10000，再通过数据菜单选择对应样本并替换。导入后核对条数再计时；测试结束后可恢复原备份。基线程序本身不会填充开发应用，也不会修改系统剪贴板。

## 8. 缺陷记录与合入条件

每个失败项记录以下内容，复现步骤只使用测试样本：

```text
用例编号：
提交 SHA / 系统与应用版本：
前置设置与权限：
复现步骤：
预期行为：
实际行为：
截图或录屏：
是否稳定复现 / 重试次数：
修复提交与复验结果：
```

合入前优先完成核心使用、键盘与权限、旧 OCR 取消、排除规则和备份回滚。会造成内容丢失、误粘贴或隐私排除失效的问题修复并复验后，再决定合入。暂时没有对应设备的多屏项目保留阻塞原因。

当前结论：自动测试已有成功记录；本表尚未执行 Mac GUI 验收，不据此宣称实机通过。
