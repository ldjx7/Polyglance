# Polyglance v0.0.2

0.0.2 正式版，汇总 beta.1–beta.6 的全部改进与修复。

## 主要更新

- 翻译速度优化：进程级 HTTP 连接复用、内存 LRU 翻译缓存、AI 流式输出合并界面刷新，OCR 截图翻译先显示贴图再逐步填充译文。
- 新安装默认使用 Microsoft 免费翻译；严格遵循用户选择的服务，请求失败直接显示错误，不会静默切换到其他服务。
- AI 翻译新增“流式输出译文”开关（默认开启）；Google 与 Microsoft 翻译始终一次性返回完整结果。
- 录屏：GIF 帧率菜单只显示支持的选项（5/16 FPS），不再出现选择后被自动改回的情况；停止录制后预览窗口立即弹出，无需再触发其他功能。
- 修复 beta.3 / beta.4 启动即崩溃的问题。
- 发布签名采用稳定签名身份：从本版起，经 Sparkle 自动更新后无需重新授权辅助功能、屏幕录制等系统权限。

## 安装提示

首次从浏览器下载时，macOS 可能要求在 Finder 中右键“打开”一次。安装本版并完成授权后，后续版本自动更新时权限保持有效。
