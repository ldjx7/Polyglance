# Polyglance v0.0.7-beta.7

Polyglance v0.0.7-beta.7 重点优化了 macOS 多屏截图渲染性能与窗口激活焦点体验，并修复了翻译工具栏组件的编译耗时问题。

## 新增特性与优化

- **macOS 多屏截图渲染性能大幅提升**：
  - 引入基于 GPU 硬件纹理（`CALayer.contents`）与 `CAShapeLayer` 遮罩的轻量底图渲染层，彻底移除全屏位图的 CPU 软绘重绘。
  - 优化多显示器窗口布局为物理单屏隔离模式，配合精准的虚拟桌面双向坐标映射，杜绝跨屏节流延迟。
  - 优化虚拟桌面多分段直接裁剪逻辑，提升多屏截图导出与处理效率。

- **焦点与窗口激活体验修复**：
  - 移除截图激活流中过早触发的强制进程激活，确保当前正在聚焦的应用窗口不失焦、不褪色。
  - 截图选区浮层关闭或取消时，自动将输入焦点平滑恢复至先前的活跃应用窗口。

- **编译性能优化**：
  - 拆分解构 `ScreenTranslationToolbarView` 复杂视图层级，解决 Xcode 编译超时问题。
