# Polyglance v0.1.2

Polyglance v0.1.2 修复了 macOS 贴图划词选区与文字光标交互问题，新增 Windows 命令行工具支持并对分发包体积进行了深度瘦身优化。

## 核心修复与优化

### 1. 贴图文字光标与划选交互修复（macOS）
- **光标响应与取词选区恢复**：移除了非编辑状态下覆盖全图的遮挡跟踪区域，贴图悬浮至文字区域时即时呈现工字光标（iBeam），可直接划选文本并弹出胶囊菜单进行复制、翻译或快捷标注。
- **多表示形式图像 OCR 容错增强**：优化了位图数据提取流程，增加 TIFF 与位图表示形式回退机制，确保贴图取词与文档分析稳定生效。

### 2. Windows 命令行（CLI）支持与单文件精简（Windows）
- **命令行工具链接入**：支持使用 `--capture`、`--record`、`--ocr` 及 `--output` 等参数直接启动截图、录屏与免模型文字识别，支持独立无缝集成于各类自动化工作流。
- **构建体积深度瘦身**：
  - Rust 核心动态库启用跨模块优化（fat LTO）、符号剥离与异常终止配置，二进制体积缩减近 50%。
  - CLI 构建输出默认剥离离线 ONNX 冗余依赖与调试符号，单文件体积大幅下降。
  - 保留 Windows 系统免模型硬件加速录屏合成与离线文字识别支持。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.1.2-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.1.2-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.1.2-Windows-x64-Portable.zip`。
- 命令行用户可直接使用 `Polyglance-0.1.2-Windows-CLI.zip` 中的独立单文件程序。
