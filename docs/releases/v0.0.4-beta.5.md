# Polyglance v0.0.4-beta.5

本次 Beta 修复 Windows 更新检查误报“当前已是最新版本”的问题，并完善 Beta 版本之间的热更新兼容性。

## Windows 更新

- 将更新检查结果拆分为“发现更新”“已经最新”和“检查失败”三种状态。
- GitHub 请求超时、网络不可用或更新源格式异常时展示真实错误，不再误报为最新版本。
- 更新请求增加应用标识并禁用缓存，减少 CDN 缓存旧更新源的可能。
- 更新源同时提供语义版本与数字构建版本：Beta.5 以后按 `0.0.4-beta.5` 比较，同时保留 `0.0.4.3` 供 Beta.4 旧更新器识别。
- 下载或启动替换流程失败时给出明确提示和手动下载建议。

## 界面

- 修复“更新与关于”页面仍硬编码显示 `v0.0.4 (Fluent Edition)` 的问题。
- 当前版本与关于卡片统一绑定应用真实版本，只显示 `v0.0.4-beta.5`。

## 兼容性

- Beta.4 可以通过现有更新器发现 Beta.5，并使用 Windows 便携版 ZIP 完成应用目录替换。
- 如果 Beta.4 所在网络无法访问 GitHub Release 更新源，仍需手动下载 Beta.5；Beta.5 安装后会明确显示网络错误原因。

本次发布继续提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
