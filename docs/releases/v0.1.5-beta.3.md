# Polyglance v0.1.5-beta.3

本次为剪贴板历史与长截图拼接功能的第三个公开测试版，主要优化剪贴板历史窗口的悬停交互与应用焦点恢复、引入有界图片缩略图解码，并提升选区内滚动长截图的拼接稳定性。

## 新增功能与交互优化

- **剪贴板悬停与焦点恢复**：
  - 修复历史列表首次鼠标悬停时的响应延迟问题，补充悬停详情与元数据预览，并在预览取消时平滑容错。
  - 使用鼠标指针交互时自动取消键盘循环选择状态，避免指针与按键焦点冲突。
  - 从后台重新呼出历史浮窗时，准确捕获并记录当前活动的应用目标，确保选用内容后能够可靠恢复焦点并执行粘贴。
- **图片缩略图与解码性能优化**：
  - 快速选择浮窗与管理窗口支持展示剪贴板位图与图片文件缩略图。
  - 采用有界缩略图解码机制处理截图与大图副本，防止短时间内大量复制图片引起内存占用过高与界面卡顿。
- **长截图选区内滚动拼接增强**：
  - 滚动位移估算算法优先比对选区内部的核心像素变动。
  - 当选区内部像素未发生变动时，自动忽略选区外部的动态干扰，有效解决复杂滚动区域（如内嵌聊天列表、带固定侧边栏的页面）中拼接停滞的问题。

## 开始测试

1. macOS 下载 `Polyglance-0.1.5-beta.3-macOS.dmg`，安装后在设置 > 通用中开启剪贴板历史。
2. 复制文本、代码片段及多张截图，呼出快速选择浮窗，测试鼠标悬停详情、缩略图展示及跨应用粘贴焦点还原。
3. 使用长截图功能在包含局部滚动的网页或应用中进行选区长截图，验证多帧拼接效果。
4. 实机测试参考 [macOS 实机验收表](https://github.com/ldjx7/Polyglance/blob/v0.1.5-beta.3/docs/剪贴板macOS实机验收.md)；遇到异常请反馈具体系统版本、目标应用名称与复现步骤。

## 测试范围与已知限制

- 本次主要更新 macOS 客户端剪贴板交互与底层截图拼接内核；Windows 客户端本期继续沿用现有版本。
- 自动粘贴与原目标应用恢复依赖 macOS 辅助功能权限；首次使用请按系统提示授权。
- 本版本标记为 Pre-release，不替换 GitHub 正式版发布通道。
