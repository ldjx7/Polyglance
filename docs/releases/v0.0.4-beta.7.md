# Polyglance v0.0.4-beta.7

本次 Beta 重点优化 Windows 端的检查更新与自动升级交互体验，修复按钮置灰卡死问题，并在官方网站全面上线现代化独立 Landing Page 与全套指南。

## Windows 更新交互优化

- **托盘菜单即时反馈**：右键菜单点击“检查更新...”时立即弹出系统通知提示“正在检查更新，请稍候...”，避免网络延迟造成的无响应感。
- **设置页内联状态与下载进度条**：
  - 实时显示“正在连接服务器...”、“发现新版本”、“当前已是最新版本”等状态。
  - 下载更新包时实时展示百分比进度条与状态文字。
  - 增加防卡死恢复机制，更新检查或下载结束后自动重置按钮状态。

## 官方网站与设计系统

- **独立现代化 Landing Page**：摆脱文档容器样式限制，打造黑白极简风格、自适应深浅色切换、全宽导航栏与 Bento Grid 特性展示。
- **1:1 真实客户端浮窗演示**：精准对齐 Polyglance 原生单行顶部栏、双语互换胶囊、服务源选择器与十字准星像素放大镜。
- **全套指南与更新日志重构**：独立交付安装权限配置、快捷键分类矩阵、常见问题手风琴卡片以及 GitHub Releases 动态卡片流。

本次发布继续提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
