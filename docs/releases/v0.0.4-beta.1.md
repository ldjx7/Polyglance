# Polyglance v0.0.4-beta.1

本次 Beta 把与平台无关的核心逻辑下沉到 Rust 共享内核，并修复长截图与权限相关问题。

## 修复

- 修复未授予辅助功能权限时按下取词快捷键没有任何提示的问题，现在会正常弹出系统授权对话框。
- 修复长截图在部分页面上出现内容遗漏的问题：偏移搜索此前可能停在一个"看起来合理"的匹配上，导致每帧漏掉中间的内容。
- 修复长页面长截图提前结束、无法继续拼接的问题。
- 长截图采样间隔由 0.35 秒缩短到 0.18 秒，可跟上约两倍的滚动速度；帧数上限同步调整，保证总可采集长度不变。

## 优化

- 长截图偏移搜索改为依据上一帧的滚动量预测，不再每帧扫描整个搜索窗口。实测单帧耗时由固定 52 毫秒降至约 1 毫秒。
- 修正了偏移搜索在得分相同时总是判定为向下滚动的问题，向上滚动的识别更稳定。

## 内部结构

- 新增 `capture-core` Rust crate，收纳截图几何、贴图缩放、原文译文对齐、录制编码策略、截屏翻译段落聚合、长截图拼接等与平台无关的逻辑；macOS 侧改为转发调用，行为保持不变。
- OpenAI 兼容服务的流式解析与请求构造移入 Rust 共享层。

本次改动不影响已保存的设置、快捷键与系统授权。
