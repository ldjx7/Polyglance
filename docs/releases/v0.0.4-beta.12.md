# Polyglance v0.0.4-beta.12

本次 Beta 修复长截图拼接与 Windows 快捷键设置两处核心问题，并将 macOS 最低系统要求下调到 14.0，让更多设备可以安装。

## 长截图

- 修复快速滚动时画面重复或错位：重叠检测不再在遇到第一个看似匹配的位置就停下，而是搜索完整个窗口后再择优，避免把大幅滚动误判成小幅滚动。
- 新增歧义判定：当某个对齐位置与其他位置难以区分时（列表、表格、等宽正文等重复度高的内容），跳过该帧而不是猜一个位置拼上去。
- 修复框选边框被截进长图：macOS 捕获区域现在从选框内缩，并按进程排除自身窗口；Windows 在系统拒绝捕获排除时自动加宽内缩。
- 降低采集延迟：macOS 不再为每一帧重新枚举窗口列表，缩短滚动与截取之间的时间差。
- 跳帧不再无声：macOS 选框边框会闪烁提示，Windows 连续跳帧后在状态栏提示放慢滚动。

## Windows 快捷键

- 修复设置窗口中快捷键只能录制一次、再次点击输入框无反应的问题。
- 修复中文输入法激活时录到无效按键、保存后快捷键完全不生效的问题。
- 快捷键注册失败（组合被其他程序占用、无法识别）时给出托盘提示，不再静默失败。
- 保存前校验：缺少 Ctrl / Alt / Win 的组合以及多个功能重复占用同一组合会被拦截并提示。

## 系统要求

- macOS 最低版本从 15.0 下调至 14.0，下载页与开发文档同步更新。

本次发布提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
