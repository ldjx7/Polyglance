# Polyglance v0.0.8-beta.3

Polyglance v0.0.8-beta.3 带来了全新的 Windows 双通道更新架构支持（GitHub 与 Microsoft Store）、基于 Win32 原生识别的包环境分流，以及官方 MSIX 打包流支持。

## 新增特性与优化

- **Windows 双通道更新架构重构**：
  - 引入统一的 `IAppUpdateProvider` 抽象与 `UpdateProviderFactory` 工厂，彻底解耦 UI 层与底层更新实现。
  - **Microsoft Store MSIX 支持**：接入 `Windows.Services.Store` 原生 API，完全杜绝外部批处理覆盖更新行为，改由系统 Store 服务安全接管；在「关于」页面动态适配 Store 渠道，自动管理更新通道。
  - **GitHub 渠道完整保留**：Inno Setup 安装版与 Portable 便携版完整保留原有 appcast 检测、ZIP 下载、校验与自动升级覆盖链路。
  - **底层防御性双保险**：在底层更新准备与批处理执行阶段加入运行时包环境检测，坚决阻断在受限包环境下的破坏性文件覆盖。

- **MSIX 打包工程与构建支持**：
  - 新增独立的 `Polyglance.Package` 打包工程，声明 `runFullTrust` 受限权限并预留 Partner Center 产品标识占位符。
  - 新增自动化打包脚本 `build-windows-msix.ps1`，CI 与 Release 自动化流水线已全面集成 MSIX 构建与分发。

- **全面单元测试覆盖**：
  - 增加包身份识别算法测试、渠道工厂解析测试、基于 Mock 的应用商店更新状态全流程测试以及包环境防御性拦截测试。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.0.8-beta.3-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.0.8-beta.3-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.0.8-beta.3-Windows-x64-Portable.zip`。
- 如需测试 Microsoft Store 包，可下载 `Polyglance-0.0.8-beta.3-Windows-x64.msix`。
