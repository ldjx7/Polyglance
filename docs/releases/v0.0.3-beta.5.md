# Polyglance v0.0.3-beta.5

本次 Beta 带来多项 UI 视觉现代化升级与交互细节优化。

## 更新内容

- **主翻译窗口视觉优化**：
  - 顶部内边距与红绿灯控制按钮精确对齐，优化语言切换胶囊垂直居中。
  - 原文与译文输入卡片内边距与占位文本基准线统一。
  - 新增 `⌘Z` 撤销恢复支持，支持清空内容后快捷撤销恢复。
  - 窗口置顶按钮重构为微胶囊悬停样式。

- **截图与录屏工具栏体验升级**：
  - 截图工具栏布局重构，复制按钮置于最右侧，并统一所有按钮为优雅灰白色调。
  - 截图与截屏翻译的选区边框线条加粗至 2.0pt，触控手柄优化为清晰圆角白点。

- **截屏翻译悬浮菜单栏重构**：
  - 彻底重构为 SwiftUI 现代暗色毛玻璃全圆角胶囊（CleanShot X 质感）。
  - 内嵌极简语言选择器与矢量对照切换模式。

- **系统权限与构建优化**：
  - 优化屏幕录制与辅助功能权限申请流程，避免重复弹窗。
  - 构建脚本自动区分本地开发（Polyglance Dev）与正式发布（Polyglance）。
