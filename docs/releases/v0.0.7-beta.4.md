# Polyglance v0.0.7-beta.4

Polyglance v0.0.7-beta.4 改进了 macOS 截图时的窗口焦点与阴影保留效果，并完善了设置窗口和 Windows 托盘图标的应用信息展示。

## 修复与优化

- **macOS 截图效果修复**：
  - 截图选区改为非激活面板，避免开始截图时抢占当前应用的激活状态。
  - 在 macOS 26 及更高版本使用截图专用配置，保留窗口边框、圆角和阴影效果。
  - 旧版 macOS 继续使用兼容的屏幕流截图配置。

- **macOS 设置窗口优化**：
  - 打开设置时显示完整的 Polyglance 应用菜单，并在关闭设置后恢复后台辅助应用模式。
  - 设置窗口每次打开时在鼠标所在屏幕的可用区域居中显示。
  - 设置侧栏加入应用图标、名称和简要说明。

- **Windows 应用信息修复**：
  - 托盘图标的鼠标悬停提示改为仅显示 Polyglance，不再显示版本号。
