# Polyglance v0.0.3-beta.4

本次 Beta 完成项目改名收尾，移除代码与配置中残留的旧名称。

## 更新内容

- macOS 应用的构建目标、模块、可执行文件与源码目录全部改名为 Polyglance。
- 内部标识符统一为 Polyglance 命名：钥匙串服务名、后台队列标签、录屏与截图的临时文件名、全局快捷键签名码。
- 更新 README 与项目方案文档中的旧目录名说明。

## 升级提示

钥匙串服务名随本次改名调整。**如果此前在设置中配置过“自定义 AI”的 API Key，升级后需要重新填写一次**；使用 Google、Microsoft 免费翻译或内置免费 AI 的用户不受影响，无需任何操作。

其他设置（默认翻译服务、目标语言、全局快捷键、录屏设置、流式开关）均照常保留。
