# Polyglance v0.0.2-beta.5

本次 Beta 修复 v0.0.2-beta.3 / v0.0.2-beta.4 启动即崩溃、完全无法打开的问题。

## 修复内容

- 修复应用启动时立即崩溃的问题：此前发布签名启用了 hardened runtime，其附带的 library validation 要求内置框架与主程序 Team ID 一致，而自签名证书没有 Team ID，导致系统拒绝加载内置的 Sparkle.framework，应用在启动阶段即被终止。现发布签名不再启用 hardened runtime。
- 用于跨版本延续辅助功能、屏幕录制等系统授权的稳定签名身份（designated requirement）保持不变，不受本次修复影响。

## 测试提示

这是测试版本。首次安装本版本并完成授权后，后续版本通过 Sparkle 自动更新时无需重新授权。
