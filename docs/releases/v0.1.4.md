# Polyglance v0.1.4

Polyglance v0.1.4 修复了 macOS 状态栏检查更新过程中的会话竞争与焦点争抢问题，提升了检查更新的稳定性与交互体验。

## 核心更新与优化

### 1. macOS 检查更新会话竞争与卡死修复
- **异步解耦模态追踪**：状态栏菜单触发检查更新时改为异步派发，脱离 `NSEventTrackingRunLoopMode` 模态追踪，避免菜单关闭与更新探测并发冲突。
- **底层更新会话等待与轮询重试**：针对应用启动初期或后台自动轮询阶段并发调用检查更新的场景，增加底层 `canCheckForUpdates` 状态等待机制，杜绝 Sparkle 底层静默丢弃请求导致前端永远停留在检查中的问题。
- **超时兜底与请求超时限制**：为检查更新状态增加 15 秒前端超时重置保护，并为 GitHub API 资源解析增加 8 秒网络超时限制，避免无网络或网络受限时无限期等待。

### 2. macOS 焦点管理与窗口抢占优化
- **避免非必要前台强激活**：优化 `showUpdateInFocus` 逻辑，在设置窗口已经可见时不再重复调用 `NSApp.activate(ignoringOtherApps: true)`，解决检查更新期间切换至其他应用或窗口时被自动切回的问题。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.1.4-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.1.4-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.1.4-Windows-x64-Portable.zip`。
- 命令行用户可直接使用 `Polyglance-0.1.4-Windows-CLI.zip` 中的独立单文件程序。
