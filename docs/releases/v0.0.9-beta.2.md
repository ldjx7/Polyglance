# Polyglance v0.0.9-beta.2

Polyglance v0.0.9-beta.2 进一步完善贴图文字交互与标注体验，双端对齐 PixPin 风格的文本划选工具栏、快捷标注与撤销，并重构 macOS 端的文本切分与渲染逻辑。

## 新增特性与优化

### 1. 贴图文字划选与工具栏
- **文本选择与复制**：贴图后光标悬浮至文字区域可直接划选单字或单词，支持快捷键复制（macOS ⌘C / Windows Ctrl+C）选中文本。
- **胶囊工具栏**：选中文本后自动弹出白底黑字胶囊工具栏，提供复制、荧光笔（黄色高亮）、波浪线（红色下划波浪）、直线（红色下划线）、删除线（灰色）及划词翻译。
- **标注撤销**：贴图文本标记操作支持通过 ⌘Z / Ctrl+Z 快捷撤销。
- **移动防冲突**：按住 Option 或 Ctrl 键配合鼠标左键可强制拖拽移动贴图，避免文字密集区域拖拽移动与选词操作冲突。

### 2. 双端样式统一与视觉优化
- 标记线条颜色统一规范，直线下划线与波浪线下划线均采用醒目红色，删除线采用中性灰。
- 工具栏按钮命名统一为「直线」，自适应按钮布局，修复 macOS 菜单栏按钮拉伸不均问题。

### 3. macOS 文本切分与渲染重构
- 拆分字符级片段与字形加权比例切分，彻底消除英文状态下整词整句大块选中的问题，实现与 Windows 一致的逐字微块选中效果。
- 修复 Vision 单词字符外接矩形重叠引起的多次重叠渲染变深问题，荧光笔对连续选中文本聚合为单层高亮，杜绝字迹遮挡。
- 划选拖拽逻辑对齐 Windows 几何相交判定，选词更平滑跟手。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.0.9-beta.2-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.0.9-beta.2-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.0.9-beta.2-Windows-x64-Portable.zip`。
- Windows 应用商店测试用户可下载 `Polyglance-0.0.9-beta.2-Windows-x64.msix`。
