# Polyglance v0.0.8

Polyglance v0.0.8 是一个重大正式版本，带来了 macOS 15+ 原生 Apple Translation 离线集成、独立「截图与录屏」设置面板、Windows 双通道更新架构（GitHub 与 Microsoft Store）、官方 MSIX 商店打包支持以及多项界面与交互体验优化。

## 新增特性与核心优化

### 1. Windows 双通道更新与 Microsoft Store 支持
- **双通道更新架构**：引入统一的 `IAppUpdateProvider` 抽象与 `UpdateProviderFactory` 工厂，彻底解耦界面层与底层更新机制。
- **Microsoft Store MSIX 支持**：
  - 深度集成 `Windows.Services.Store` 原生 API，由系统商店服务安全管理更新流程与下载进度，杜绝批处理覆盖破坏。
  - 配置 Microsoft Partner Center 开发者身份，提供专属 MSIX 包。
  - 「关于」页面动态识别运行环境，针对商店版本隐藏手动更新通道开关与跳过版本选项。
- **GitHub 渠道完整保留**：
  - Inno Setup 安装版与 Portable 便携版继续使用 appcast 检测、ZIP 下载校验与自动覆盖升级链路。
  - 增加运行时包环境检测，在受限包环境下坚决阻断覆盖操作。

### 2. Apple Translation 原生翻译支持（macOS 15+）
- 在 macOS 15.0 及更高版本系统上，深度集成系统内置的 Apple Translation 框架，无需配置 API Key 即可使用官方离线语言包进行高质量翻译。
- 针对 macOS 14.x 系统增加兼容性检查与平滑降级提示，未达系统最低版本要求时自动禁用并给出明确提示，确保运行稳定性。

### 3. 独立「截图与录屏」设置面板（双端对齐）
- 梳理并重构设置页导航体系，新增「截图与录屏」专属面板，集中管理截图历史自动归档、录屏导出格式（MP4 / GIF）、帧率、倒计时、音频录制偏好与存储目录。
- 「工具栏」设置页精简专精，专注于截图工具栏图标排布、拖拽排序与功能储备池开关。
- Mac 工具栏设置页面支持实时监听窗口尺寸，自适应等比缩放生效胶囊栏与功能储备池卡片尺寸、图标与字号，窗口缩小时平滑回退，杜绝文字截断。

### 4. 翻译交互与工作流优化
- **重新翻译与重试**：
  - 翻译窗口支持全局「重新翻译」（快捷键 ⌘R / Ctrl+R），一键重试所有已启用服务。
  - 独立翻译卡片支持单独「重新翻译」按钮，便于单个服务网络波动时按需重试。
  - 修复 macOS 翻译窗口原文输入框快捷键操作失效问题。
- **Windows 划词翻译与替换增强**：
  - 优化划词翻译流程，支持将译文一键替换回当前光标选中的文本。
  - 支持离线模型与本地数据目录的统一管理与存储路径自定义。

### 5. 界面展示与交互细节优化
- 官网补齐真实产品界面展示区，涵盖 macOS 流式翻译、Windows 原生窗口、离线二维码识别与 OCR 文本分词工作区。
- 补充 macOS Gatekeeper 隔离拦截解决方案（系统设置放行、访达右键打开、终端命令解除）。
- Mac 设置窗口尺寸调整至 900 × 580，提供更加宽敞舒展的布局体验；已打开设置窗口时再次唤起直接置顶激活。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.0.8-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.0.8-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.0.8-Windows-x64-Portable.zip`。
- Windows 应用商店用户可使用官方 `Polyglance-0.0.8-Windows-x64.msix`。
