# Polyglance v0.0.8-beta.2

Polyglance v0.0.8-beta.2 带来了 macOS 15+ 原生 Apple Translation 离线翻译集成、系统版本兼容性检测，以及针对官网与项目文档的全面优化。

## 新增特性与优化

- **Apple Translation 原生翻译支持（macOS 15+）**：
  - 在 macOS 15.0 及更高版本系统上，深度集成系统内置的 Apple Translation 框架，无需配置 API Key 即可使用官方离线语言包进行高质量翻译。
  - 针对 macOS 14.x 系统增加兼容性检查与平滑降级提示，未达系统最低版本要求时自动禁用并给出明确提示，确保运行稳定性。

- **产品界面展示与交互指引完善**：
  - 官网新增真实产品界面展示区，涵盖 macOS 流式翻译、Windows 原生窗口、离线二维码识别与 OCR 文本分词工作区。
  - 补充 macOS Gatekeeper 隔离拦截的三种解决方式（系统设置放行、访达按键右键打开、终端命令解除），降低首次上手门槛。

- **文档与架构说明升级**：
  - 优化项目 README 文档版式与技术规范说明，清晰呈现纯原生跨平台架构、系统权限需求与本地编译步骤。

## 下载与升级

- macOS 用户推荐下载 `Polyglance-0.0.8-beta.2-macOS.dmg`。已安装的用户可通过菜单栏「检查更新…」直接获取在线推送。
- Windows 用户推荐下载 `Polyglance-0.0.8-beta.2-Windows-x64-Setup.exe`，或使用 `Polyglance-0.0.8-beta.2-Windows-x64-Portable.zip` 便携版。
