# Polyglance v0.1.3

Polyglance v0.1.3 升级了 Windows 屏幕录制引擎，优化了双端录制交互体验与快速保存流程。

## 核心更新与优化

### 1. Windows 硬件级录屏采集与性能优化
- **Direct3D 11 硬件采集引擎**：底层基于 Windows.Graphics.Capture 与 Direct3D 11 帧池实现显存直读，替代高开销的 GDI 轮询方案，大幅降低录屏时的 CPU 占用与帧间隔抖动。
- **无感边缘裁切与边框控制**：自动隐藏黄色录制边框，在 GPU 显存内快速完成选区裁切；对环境受限平台支持自动回退至兼容采集路径。
- **多显示器与高 DPI 选区框贴合修复**：重构录屏边框窗口定位逻辑，修正物理像素与设备无关像素转换基准，解决跨屏幕及非标准缩放比例下录屏选区红框与控制工具栏位移问题。
- **单调递增时间戳与进度控制**：重构录屏音视频混流合成时间轴与播放时钟，解决部分播放器中进度条卡顿与跳跃问题。

### 2. 双端快速保存与目录提示增强
- **规范化保存路径与命名**：录屏快速保存文件统一采用应用名前缀命名，并保存至配置目录下的专属视频文件夹。
- **快速保存提示窗口重构**：
  - Windows 端升级为原生卡片式布局，优化界面排版并去除多余空白区域；
  - 提示弹窗提供「打开目录」快捷按钮，支持在资源管理器中直接定位并选中录制完成的文件。

### 3. macOS 录屏权限与视觉交互优化
- **麦克风权限提前检测**：录制前及开启音频选项时即时校验麦克风授权状态；未获得授权时将麦克风控制置灰，并在偏好设置的系统权限中提供快捷管理入口，避免录制结束后生成视频时延迟弹窗。
- **工具栏视觉对比度优化**：开始录制按钮调整为醒目的红色录制样式；录制进行中暂停与停止按钮显式呈现为纯黑色高亮，未录制时保持灰色。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.1.3-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.1.3-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.1.3-Windows-x64-Portable.zip`。
- 命令行用户可直接使用 `Polyglance-0.1.3-Windows-CLI.zip` 中的独立单文件程序。
