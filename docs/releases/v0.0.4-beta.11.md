# Polyglance v0.0.4-beta.11

本次 Beta 重点修复 Windows 跨版本更新，并重新整理 macOS 与 Windows 的默认快捷键，降低与常用开发工具和系统快捷键发生冲突的概率。

## Windows 更新修复

- 修复从旧版更新后仍可能启动旧的 `Polyglance.UI.exe`，导致版本看似没有更新的问题。
- 更新包同时提供新旧入口兼容层；更新完成后优先启动新版 `Polyglance.exe`，并清理已废弃的旧入口文件。
- CI 新增便携更新包结构与兼容入口校验，避免发布不可替换或无法重启的更新包。

## 跨平台快捷键调整

- 截图并贴图：`Ctrl + Shift + 1`
- 贴出剪贴板图片：`Ctrl + Shift + 2`
- 翻译选中文字：`Ctrl + Shift + 3`
- 截图翻译：`Ctrl + Shift + 4`
- 长截图、录屏、恢复贴图和打开主翻译窗口默认不占用快捷键，用户可在设置中按需配置。
- 完整使用旧默认快捷键的用户会自动迁移；已经自定义过的快捷键保持不变。
- 快捷键录制支持使用 Delete 或 Backspace 清除当前绑定。

本次发布提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
