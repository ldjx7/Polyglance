# Polyglance v0.0.4-beta.3

本次 Beta 首次提供 Windows 客户端，并继续完善 macOS 与 Windows 的录屏、长截图、OCR 和截图翻译体验。

## Windows

- 新增 Windows x64 客户端，Release 同时提供免安装便携版 ZIP 和带卸载逻辑的安装版 EXE。
- 支持翻译、自定义快捷键、开机自启、截图与标注、贴图、OCR、截图翻译、长截图和录屏等主要能力。
- 截图工具栏的图标、颜色和交互向 macOS 端对齐；截图翻译归入翻译操作区域。
- OCR 支持识别结果选择与复制，截图翻译和长截图翻译复用统一流程。
- 长截图支持手动向上、向下滚动采集和实时缩略图，并修复只保存首帧、拼接结果带选区蓝框的问题。
- 录屏支持 MP4/GIF、系统声音、麦克风和鼠标指针选项；修复指针显示为方块、无麦克风时无法继续录制等问题。

## macOS

- 新增开机自启设置。
- 完善 MP4 录屏的系统声音与麦克风混音，并修正光标选项和录制工具栏交互。
- 优化翻译窗口的原文/译文对照与交互表现。

## 跨平台与发布

- 新增 Rust C ABI 共享层，统一截图几何、录制参数、长截图拼接和原文译文对齐等跨平台能力。
- Tag 构建会同时发布 macOS ZIP、macOS DMG、Windows 便携版 ZIP 和 Windows 安装版 EXE。
- 补充跨平台架构约束与 Bob 风格 OCR/截图翻译改造文档，为后续两端持续对齐提供依据。

这是 Windows 首个公开 Beta，建议优先使用便携版验证；如遇问题，请在 GitHub Issues 中附上系统版本和复现步骤。
