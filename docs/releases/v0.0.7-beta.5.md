# Polyglance v0.0.7-beta.5

Polyglance v0.0.7-beta.5 带来了双端标注二次编辑完整能力、滚轮动态粗细与字号缩放，并完善了快捷键与边界交互防护。

## 新增特性与优化

- **截图标注二次编辑**：
  - 支持已绘制图元的再次选中、8 向手柄拉伸与端点拖拽调整。
  - 支持选中图元的整体移动平移。
  - 支持双击已固化文本图元原地重新编辑，失焦自动提交。
  - 选中图元时工具栏双向联动，实时调节颜色、填充、虚线、粗细及文本样式。
  - 支持快捷键 Delete / Backspace 删除选中图元，Esc 取消选中。

- **滚轮动态缩放与序号标记优化**：
  - 选中标注图元或序号时，支持滚动鼠标滚轮实时调节线条粗细或圆圈大小。
  - 修复序号标记图元中心锚点重算与字号自适应比例。
  - 优化 macOS 滚轮撤销事务合并，避免单次滚动产生冗余历史记录。
  - 增加文本输入过程中的按键隔离防护，避免编辑时退格误删图元。
