# Polyglance v0.0.6

Polyglance v0.0.6 带来了全新的**测试版与正式版更新通道隔离机制**、**智能免打扰主动推送**、**官网免费 AI 翻译精准直译规范**以及双端体验的全面升级。

## 更新通道隔离与测试版尝鲜机制

- **正式版与测试版通道隔离**：
  - 偏好设置「更新与关于」新增 **「接收测试版更新 (Beta Channel)」** 切换开关。
  - 正式版构建默认仅接收经过充分验证的稳定正式版本，避免频繁变动影响日常使用。
  - 测试版与开发版构建默认开启尝鲜通道，第一时间体验最新特性。
- **智能更新源动态解析**：
  - 双端客户端在开启测试通道时，优先直接通过 GitHub Releases API 获取最新 Pre-release 描述文件与安装包，彻底解决 GitHub `/releases/latest/` 仅重定向至稳定版导致测试版无法检出的问题。
- **指定版本跳过**：
  - Windows 端检测到新版本后，支持点击 **「跳过此版本」**，在该版本被更高版本替代前不再弹窗打扰。
- **版本类型胶囊徽标**：
  - 设置页面清晰展示当前构建类型（`[正式版 🟢]` / `[Beta 尝鲜 🧪]`）。

## 后台智能静默推送（免手动检查）

- **双端后台主动轮询**：
  - Windows 端启动 10 秒后静默发起首轮检查，运行期间每 6 小时静默轮询一次。
  - macOS 端完整集成 Sparkle 2 原生静默更新调度。
- **托盘菜单与系统通知直观联动**：
  - 发现新版本时，自动弹出系统原生 Toast/通知气泡。
  - 托盘右键菜单顶层动态插入带醒目标识的快捷更新项（`🚀 发现新版本 / 🧪 发现新测试版`），点击一键直达。

## 免费 AI 翻译精准直译规范

- **消除词典释义冗余**：
  - 针对腾讯 Hunyuan-MT-7B 专用翻译微调模型优化原生中文指令，彻底解决单单词（如 `locale`、`interface`）或专业术语被误判为词条百科而输出大段释义的问题。
  - 严格确保纯净直译输出，保持 0.6 秒极速响应。

## 下载与更新

本次发布提供 macOS Universal（ZIP / DMG）以及 Windows x64 便携版 ZIP 与独立安装包 EXE。
