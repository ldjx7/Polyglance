# Polyglance v0.1.5-beta.1

本次为剪贴板历史功能的首个公开测试版，重点测试 macOS 的复制记录、搜索、快捷键和粘贴交互。历史默认关闭，需要在设置中主动开启。

## 新增功能

- 本地保存文字、HTML / RTF 富文本、图片、文件引用及多项剪贴板内容，支持去重、搜索、类型 / 来源 / 标签筛选。
- 支持收藏、名称和标签、固定文本编辑、单条删除及批量清理；可设置条数、内容容量和保留天数。
- 支持键盘导航、数字快速选择、固定项字母快捷键、修饰键循环选择，以及可自定义的历史呼出和连续粘贴快捷键。
- 支持原格式复制、自动粘贴、纯文本粘贴、多选复制和逐条连续粘贴；自动粘贴需要 macOS 辅助功能权限。
- 历史图片可直接贴图、识别文字和二维码；可选择开启本机 OCR 索引，通过图片中的文字搜索历史。
- 支持暂停记录、忽略来源应用、敏感类型和内容正则排除、仅忽略下一次复制，以及系统剪贴板清空后的对应记录移除。
- 支持 `.polyclipboard` 备份导出、合并、替换和损坏恢复；增加八个 Apple 快捷指令动作及可选通知。

## 最近修复

- 修复列表选择与输入法组合状态、快速连续采集、历史重放及 OCR 任务中的多项问题。
- 关闭或重开历史窗口、切换条目、清空或导入时取消旧的手动 OCR，避免迟到结果再次打开窗口。
- 公共 Rust 核心在解析图片前校验 PNG 尺寸，统一限制采集和备份导入中的图片像素；无效导入整批回滚。
- 编辑固定文本后按纯文本保存，移除旧的 HTML / RTF，同时保留名称、标签、收藏和快捷键。

## 开始测试

1. macOS 下载 `Polyglance-0.1.5-beta.1-macOS.dmg`，安装后从菜单栏打开剪贴板历史。
2. 点击历史窗口中的设置，开启在本机保存复制内容和文件引用，再复制新的内容。开启前的旧剪贴板不会补录。
3. 在现有偏好设置的快捷键页面配置剪贴板历史和粘贴下一条历史；这两个快捷键初始未分配，可将呼出键设为 Command+Shift+V。
4. 使用 Enter 复制、Option+Enter 自动粘贴、Option+Shift+Enter 纯文本粘贴。首次自动粘贴按系统提示授予辅助功能权限。
5. 按 [macOS 实机验收表](https://github.com/ldjx7/Polyglance/blob/v0.1.5-beta.1/docs/剪贴板macOS实机验收.md) 测试跨应用粘贴、中文输入法、权限、多屏、OCR 取消和备份恢复；反馈时附应用版本、系统版本及复现步骤。

此 beta 使用发布应用 `Polyglance.app`，与正式版使用同一应用身份，安装时会替换正式版；与此前 CI 提供的 `Polyglance Dev.app` 分开保存数据。开发版历史如需迁入，可先导出备份，再在 beta 中手动导入。

## 测试范围与已知限制

- 当前开发分支的 macOS 原生 CI 已通过 Rust workspace 249 项测试；Swift 执行 600 项，0 失败、3 项现有录屏夹具测试跳过。应用构建、签名检查及八个快捷指令的元数据检查通过。Windows 公共剪贴板核心 40 项测试通过。记录见 [验证文档](https://github.com/ldjx7/Polyglance/blob/v0.1.5-beta.1/docs/CLIPBOARD_HISTORY_VALIDATION.md)。
- 权限、真实应用焦点、多屏和长期能耗仍需实机测试；自动测试通过不代表这些交互已经验收。
- 历史采集采用 200 ms 轮询，两次采样之间的快速复制不保证全部保留。文件历史只保存引用，不复制文件本身。
- 历史和导出备份未加密；默认不上传、不跨设备同步，主动点击翻译时使用已有翻译服务。敏感过滤依赖来源提供的标记及用户设置，不能识别所有以普通文本复制的密码。
- Windows 剪贴板界面尚未接入。本次 Windows 发布包沿用现有客户端；Rust + Slint 重构分支及其长截图修改不包含在这个 beta 中。
- 已建立 500 / 10000 条历史的三平台性能基线；Windows CI 中 10000 条满容量写入的 P95 约为 297 ms，后续接入新界面前需要在目标机器继续分析。详见 [性能基线](https://github.com/ldjx7/Polyglance/blob/v0.1.5-beta.1/docs/剪贴板性能基线.md)。

本版本标记为 Pre-release，不替换 GitHub 的最新正式版。用户可手动下载安装，也可在已安装版本中开启接收测试版更新后检查更新。
