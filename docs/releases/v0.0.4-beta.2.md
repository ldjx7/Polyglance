# Polyglance v0.0.4-beta.2

本次 Beta 修复默认翻译服务无法使用的问题。

## 修复

- 修复 Microsoft 免费翻译始终失败的问题。该服务的接口会拒绝未表明来源的请求，而应用此前没有携带这一信息，导致翻译请求被直接拒绝。由于 Microsoft 是新安装的默认服务，受影响的用户需要手动切换到 Google 或 AI 翻译才能使用。现已修复，无需任何设置改动。

## 内部结构

- 翻译服务的选择、配置构造与免费服务的隐私策略移入 Rust 共享层，绑定层只保留运行时与类型转换，便于后续 Windows 端复用同一套逻辑。

本次改动不影响已保存的设置、快捷键与系统授权。
