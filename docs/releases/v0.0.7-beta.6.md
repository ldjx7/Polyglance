# Polyglance v0.0.7-beta.6

Polyglance v0.0.7-beta.6 支持配置多个自定义 AI 翻译服务、引入翻译历史记录、优化截图激活速度，并完善多引擎翻译设置与交互。

## 新增特性与优化

- **多自定义 AI 翻译服务支持**：
  - 支持添加多个独立的自定义 OpenAI 兼容 AI 翻译服务，不再局限于单一配置。
  - 支持配置服务名称、接口地址、API Key、模型名称以及自定义系统提示词（Prompt）。
  - 支持对多个 AI 服务进行重命名、独立启闭与删除管理。

- **翻译设置与服务排序体验升级**：
  - 翻译服务管理收归至翻译设置统一面板。
  - 双端对齐服务拖拽排序交互与实时状态切换。

- **翻译历史记录窗口**：
  - 支持查看历史翻译记录与多服务卡片对照。
  - 支持一键复制原文与译文、快速检索与批量管理。

- **截图激活与识别响应加速**：
  - 优化 macOS 多显示器并行捕获流程，大幅降低激活延迟。
  - 修复多屏环境下的窗口吸附与悬停边界判定。

- **输入框与交互修复**：
  - 修复清空输入框时译文卡片即时清除逻辑，支持再次输入相同或新内容正常触发翻译。
