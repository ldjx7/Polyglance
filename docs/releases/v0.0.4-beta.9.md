# Polyglance v0.0.4-beta.9

本次 Beta 将 Windows 端主程序执行文件名及程序元数据属性从 `Polyglance.UI.exe` 统一规范命名为 `Polyglance.exe`。

## Windows 产物规范化

- **程序文件名**：可执行文件由 `Polyglance.UI.exe` 正式更名为 `Polyglance.exe`。
- **程序属性元数据**：清理所有 `.UI` 命名空间后缀，程序名称、产品说明与描述属性统一规范为 `Polyglance`。
- **安装与更新脚本同步**：安装包快捷方式、自启动注册、进程终止与热更新替换脚本均全面适配 `Polyglance.exe`。

本次发布继续提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
