# Polyglance v0.0.3

0.0.3 正式版，汇总 beta.1–beta.5 的全部改进与修复。

## 主要更新

- **PixPin 风格白底全圆角截图工具栏**：
  - 截图工具栏升级为纯白实体胶囊设计（22pt 全圆角），支持硬件级切片遮罩（`maskImage`）与精准阴影跟随；
  - 统一深黑高辨识度图标设计与轻浅灰 Hover 悬停交互，选中/禁用状态对比分明。
- **截屏翻译悬浮工具栏重构**：
  - 截屏翻译采用现代悬浮毛玻璃胶囊（SwiftUI 架构），支持即时语言选择、译文对照高亮切换与原图贴图保存。
- **选区框选与控制点质感提升**：
  - 截图与截屏翻译边框线条统一加粗至 2.0pt，选用 7×7pt 纯白圆点 + 1.5pt 微高光控制手柄，拖拽与尺寸微调更灵敏。
- **权限与设置优化**：
  - 优化权限申请逻辑，避免重复弹窗；未授权时保持静默，不主动干扰用户操作；
  - 状态栏菜单与偏好设置页面新增应用版本信息展示。
- **稳定性与测试**：
  - 修复多处右键菜单交互与边界测试断言，全部 394 项单元测试 100% 验证通过。

## 安装提示

首次从浏览器下载时，macOS 可能要求在 Finder 中右键“打开”一次。安装本版并完成授权后，后续版本自动更新时权限保持有效。
