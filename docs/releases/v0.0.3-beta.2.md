# Polyglance v0.0.3-beta.2

本次 Beta 将“截屏翻译”的交互全面对齐有道翻译。

## 更新内容

- 选区常驻可调：红色边框配八向圆形手柄，翻译结果显示后仍可拖动手柄调整范围、拖动内部移动位置，松手自动重新识别并翻译；拖动过程实时预览画面。
- 全新工具条（选区下方）：源语言（默认自动检测）与目标语言选择、一键互换；“对照”开关在译文覆盖与原图之间切换；复制译文；提取文本（弹出原文/译文结果卡）；重新截取；钉住（把当前效果转为普通贴图）；刷新（重新抓取屏幕当前内容并重新翻译）；关闭。
- 译文保留原文字色：按原图逐段采样文字颜色，链接、强调色等在译文中保持一致；采样不可靠时按背景明暗自动回退。
- 钉住导出的贴图按 Retina 分辨率渲染，画质清晰。

## 测试提示

这是测试版本。段落聚合、取色与字号适配会根据实际画面继续调优；“刷新”适合页面内容变化后原位重译。
