# Polyglance v0.0.4-beta.6

本次 Beta 继续统一 macOS 与 Windows 的截图、贴图、取色、标注和 OCR 交互，并修复标注内容未进入最终贴图/复制/保存结果的问题。

## 取色与放大镜

- macOS 与 Windows 统一显示 `C 复制色值 · ⇧C 切换 HEX/RGB`。
- 复制成功后短暂显示“已复制”提示，复制后继续保留当前截图或贴图。
- 修正高 DPI 与图像边缘采样坐标，确保准星指向的像素就是实际复制的颜色。
- 贴图右键菜单新增“取色”，无需重新截图即可读取贴图像素。
- Windows 取色不再依赖界面文本，统一从像素采样数据生成 HEX、RGB 和坐标信息。

## 标注交互

- macOS 与 Windows 新增统一的序号标记图标与标注能力。
- 修复 macOS 贴图标注模式中文字无法正常输入的问题。
- 文字标注创建后支持移动位置。
- Windows 标注工具栏在切换画笔、形状、马赛克等工具时保持完整，不再弹出额外工具栏。
- Windows 标注鼠标统一为小十字，箭头、画笔和连续涂抹式马赛克行为向 macOS 对齐。
- 进入标注后选区继续保持蓝色边框，并支持从边缘和拐角扩大或缩小选区。
- 调整选区时保留已经绘制的标记；贴图、复制和保存结果会正确合成标注图层。
- 贴图右键菜单补充重新进入标注模式的入口。

## OCR

- Windows OCR 交互向 macOS 对齐，识别结果在原截图/贴图上进入文字选择，不再强制打开独立复制窗口。
- OCR 文字选择支持退出后继续使用贴图及其右键菜单。

## 构建与权限

- macOS 本地开发构建会退出旧进程，并准确重置辅助功能、屏幕录制和麦克风权限。
- macOS 构建会验证固定自签名证书指纹；本地钥匙串签名不可用时可安全回退到 ad-hoc 调试签名。
- Windows 本地构建会退出旧进程并重试清理被系统短暂占用的历史产物，确保只保留本次构建结果。

本次发布继续提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
