# Polyglance v0.0.4-beta.10

本次 Beta 彻底移除 Windows 端所有的模态对话框弹窗，全面转向右下角系统气泡通知与设置界面纯内联进度更新。

## Windows 更新交互优化

- **无弹窗静默/气泡通知**：右键托盘“检查更新”在发现新版本时，通过右下角气泡通知提示并自动启动后台下载与重启，彻底移除 `MessageBox` 弹窗。
- **设置界面纯内联交互**：偏好设置内点击“立即检查更新”直接进入内联下载与百分比进度条状态，全流程无模态弹窗打扰。

本次发布继续提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
