# Polyglance v0.1.0

Polyglance v0.1.0 是里程碑正式版本，全新推出跨平台滚动长截图系统、贴图文字划选与标注工具栏、Microsoft Store 官方商店打包支持，并在 macOS 与 Windows 双端实现了更深度的交互体验对齐。

## 新增特性与核心优化

### 1. 跨平台滚动长截图系统
- **动态滚动拼接**：支持在长网页、文档和长聊天记录中滚动截取，采用几何对齐与重叠判定算法，拼接自然平滑。
- **操作反馈与速度提示**：内置滚动速率与位移监测，在滚动过快导致丢帧时实时提示「请慢速平稳滚动页面」，引导平稳捕获。
- **视口缩略图同步**：长截图浮层提供完整缩略图预览与绿色动态视口指示框，实时追踪当前可视区域，跟随滚动上下同步映射。
- **滚轮事件定向穿透**：优化 Windows 与 macOS 下的底层事件路由，光标位于框选区域内时滚轮精准驱动底层目标窗口滚动。

### 2. 贴图文字划选与标注工具栏
- **精准文字划选**：贴图后鼠标光标悬停于文字区域可逐字或逐词精准划选，支持快捷键复制选中文本。
- **浮动胶囊工具栏**：选中文本后自动弹出胶囊工具栏，提供复制、荧光笔高亮、下划波浪线、直线下划线、删除线以及划词翻译。
- **标注撤销与手势保护**：支持使用 ⌘Z / Ctrl+Z 快速撤销贴图文字标注；支持按住 Option 或 Ctrl 键强制拖拽移动贴图，避免选词交互与贴图移动冲突。
- **双端样式与渲染统一**：对齐 macOS 与 Windows 的文本切分与渲染逻辑，优化文字遮罩层与高亮边缘，杜绝重叠渲染加深与字迹遮挡。

### 3. Windows Microsoft Store 官方支持
- **合规 MSIX 包**：全面对齐 Microsoft Partner Center 产品身份标识（Package Identity、Publisher 及 PublisherDisplayName），提供开箱即用的官方 MSIX 安装包。
- **更新通道原生适配**：支持 Windows Store 原生更新分发与 GitHub 自更新双通道并行。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.1.0-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.1.0-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.1.0-Windows-x64-Portable.zip`。
- Windows 应用商店用户可下载官方 `Polyglance-0.1.0-Windows-x64.msix`。
