# Polyglance v0.1.1

Polyglance v0.1.1 专注于贴图生命周期、缩放基准尺寸恢复与启动静默容错的稳定性修复，全面提升双端日常使用的可靠性。

## 核心修复与优化

### 1. 贴图缩放与恢复基准尺寸修复（macOS）
- **基准尺寸精确维持**：修复了贴图缩放到非 100% 比例（例如 80%）后，关闭再重新恢复时将缩放后尺寸错误当作新 100% 基准的问题。
- **连续缩放体验对齐**：会话持久化层新增原始基准尺寸记录与传递，贴图恢复后再次缩放将严格基于原始尺寸连续计算，并对齐 Windows 端的缩放行为。

### 2. 启动恢复静默容错与弹窗彻底清理（双端）
- **移除启动阻塞弹窗**：移除了 macOS 端启动阶段因历史超限触发的模态提示弹窗，历史预加载静默按活跃状态排队恢复，绝不打扰用户正常启动。
- **损坏会话毒丸隔离**：Windows 端增加贴图恢复异常隔离机制，若历史文件存在截断或损坏，自动跳过并标记失效，避免重复报错。
- **无活跃贴图快速退出**：无待恢复活跃贴图时快速退出恢复流程，消除不必要的磁盘调度。

### 3. 应用退出状态保存强化（Windows）
- **退出等待缓冲**：优化托盘退出时的异步会话落盘机制，在主程序退出时增加安全等待保障，杜绝因进程提前退出导致贴图状态文件被截断的问题。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.1.1-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.1.1-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.1.1-Windows-x64-Portable.zip`。
- Windows 应用商店用户可下载官方 `Polyglance-0.1.1-Windows-x64.msix`。
