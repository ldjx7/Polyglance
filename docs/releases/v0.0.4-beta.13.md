# Polyglance v0.0.4-beta.13

本次 Beta 将内置免费 AI 翻译迁移到 Polyglance 官方服务，并集中修复 Windows 更新后设置丢失、FreeAI 翻译失败以及双端取色体验问题。

## 免费 AI 翻译

- 内置免费 AI 不再把上游 API Key、模型或 Prompt 打包进客户端；macOS 和 Windows 只向 Polyglance 官方翻译接口发送原文与语言信息。
- 服务端固定翻译用途、模型与 Prompt，并加入请求格式校验、长度限制、分级计费额度和匿名调用频率限制，不能作为通用 AI 接口使用。
- 支持流式返回译文，同时过滤上游模型和服务商元数据。
- 修复 Windows 使用 `zh-Hans` / `zh-Hant` 时被服务端拒绝、显示“翻译服务商响应异常”的问题；客户端现在统一转换为服务端支持的语言代码。
- 构建 macOS、Windows 客户端不再需要注入免费 AI 的 API Key。

## Windows 设置与录屏

- 修复升级或便携版目录变化后“开机自启”被误判为关闭：程序会识别旧版 `Polyglance.exe` / `Polyglance.UI.exe` 注册项并迁移到当前路径。
- 补充完整配置往返测试，确认服务商、语言、快捷键、更新配置和录屏默认值存放在用户配置目录，不随应用替换而丢失。
- 默认录屏格式、帧率和倒计时现在会保存并应用到录屏工具栏；移除尚未实现却出现在设置中的 WebM 选项。
- 录制倒计时设置现在会实际执行，不再只是界面选项。

## 取色与放大镜

- macOS 与 Windows 放大镜统一显示色块、完整 HEX/RGB 色值、像素坐标和 `C` / `⇧C` 快捷键提示。
- 修复屏幕边缘取色时放大镜越界或准星偏移，确保准星对应的像素就是实际复制的色值。
- 复制色值后显示短暂成功反馈，切换 HEX/RGB 后复制结果与当前显示格式保持一致。

## 官网与发布

- 官网下载接口只接受已发布的四种客户端类型，并根据 GitHub Release 中真实存在的资产跳转；平台构建缺失时不再拼接一个必然 404 的下载地址。
- 下载统计与 Release 数据解析增加输入校验和自动化测试。
- 双端发布工作流统一使用官方免费翻译接口，不再依赖客户端构建 Secret。

本次发布提供 macOS ZIP/DMG、Windows x64 便携版 ZIP 和安装版 EXE。
