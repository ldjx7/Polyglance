# Polyglance v0.0.7

Polyglance v0.0.7 是一个重大里程碑正式版本，带来了全新的品牌视觉体系、双端内嵌式零打扰更新、截图标注二次编辑与多屏渲染优化、多 AI 自定义翻译引擎与翻译历史，以及全新的快捷键预设与权限交互体验。

## 新增特性与核心优化

### 1. 全新品牌视觉与内嵌式应用更新
- **全新品牌图标体系**：
  - 升级品牌 Logo 为截图取景框结合双语卡片设计，全平台适配应用图标（macOS .icns、Windows .ico、Web favicon）。
  - macOS 菜单栏适配单色自适应图标，根据系统深浅色模式与高亮状态动态渲染。
  - 设置页面排版升级，展示更加清晰规范。
- **内嵌式零打扰更新流程**：
  - 废弃独立弹窗打扰，所有更新检查、下载进度与就绪状态统一收敛在设置页「关于」选项卡中。
  - 支持就地准备更新，进入就绪状态后支持「稍后重启」与「立即重启」，不中断当前工作流程。
  - Windows 托盘右键菜单「检查更新…」直接唤起设置页并就地检查。

### 2. 截图标注与多屏性能优化
- **标注二次编辑与动态缩放**：
  - 支持已绘制标注（矩形、椭圆、画笔、箭头、编号、文本等）的二次选中、拖拽位移、控制点拉伸与样式微调。
  - 绘制与二次编辑状态下支持鼠标滚轮平滑调节线条粗细、箭头尺寸与文本字号。
  - 工具栏支持全局拖拽移动与停靠，边缘自动规避屏幕边界。
- **macOS 多屏与渲染性能升级**：
  - 多屏环境下采用统一物理窗口与 GPU 贴图背景隔离，消除跨屏截图撕裂与激活白屏。
  - 优化截图激活与退出时的窗口焦点机制，退出截图时精准恢复上一前台窗口焦点。
- **Windows 截图交互优化**：
  - 优化截图激活状态下右击取消操作，防止右键事件穿透至系统桌面唤起右键菜单。

### 3. 多 AI 引擎支持与翻译历史
- **支持配置多个自定义 OpenAI 兼容 AI 翻译服务**：
  - 支持添加多个自定义模型端点、API Key 与模型名称，并在翻译面板与工具栏中自由切换。
  - 优化腾讯混元专用翻译模型指令，确保专业名词精准直译、响应迅速。
- **翻译历史记录**：
  - 新增翻译历史记录面板，支持检索、快速复制原文与译文、清空历史。

### 4. 快捷键预设方案与权限交互重构
- **快捷键方案与选区内说明**：
  - 快捷键页面提供「恢复默认」、「Snipaste 风格」与「PixPin 风格」快捷预设。
  - 快捷键录制控件支持冲突检测与占用提示。
  - 双端统一补齐截图选区内固定单快捷键说明（C 复制、P 贴图、S 保存、T 翻译、O OCR 工作台、Esc 退出）。
- **macOS 权限引导交互优化**：
  - 首次触发未授权功能时仅唤起系统原生授权请求，消除多重弹窗重叠。
  - 已请求未授权时弹出自定义引导提示，协助用户一键打开系统设置。
  - 偏好设置权限项智能区分首次「请求授权」与后续「打开系统设置」。
  - 开发构建重置权限时自动同步清理请求记录。

## 下载与安装

本次正式发布提供 macOS Universal（DMG / 压缩包）以及 Windows x64 便携版与安装程序。
