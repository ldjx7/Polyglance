# Polyglance v0.0.2-beta.4

本次 Beta 主要优化翻译延迟与截图翻译的响应速度。

## 优化内容

- 新安装默认使用 Microsoft 免费翻译；升级不会擅自修改用户已经选择的翻译服务。
- 严格遵循用户选择的服务：Google、Microsoft、免费 AI 或自定义 AI 请求失败时，直接显示对应错误，不会静默切换到其他服务。
- Google、Microsoft 和 AI 翻译复用进程级 HTTP 连接池，减少重复建立连接带来的等待。
- 增加容量为 256 条的内存 LRU 翻译缓存；相同服务、语言和文本可直接复用结果。缓存不会写入磁盘，也不包含 API Key。
- 免费 AI 与自定义 AI 保持流式输出，并合并过于频繁的界面刷新，使长文本输出更平滑。
- OCR 截图翻译会先立即显示翻译贴图，再逐步填充译文，无需等待整段翻译结束。

## 测试提示

这是测试版本。若发现某个翻译服务失败，Polyglance 会保留当前服务并显示错误，方便准确判断服务或网络问题。
