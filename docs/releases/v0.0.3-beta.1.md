# Polyglance v0.0.3-beta.1

本次 Beta 新增“截屏翻译”功能，与现有“截图翻译”并存。

## 新增内容

- 截屏翻译（默认快捷键 `Option+6`，可在设置中修改）：框选屏幕区域后自动识别文字并翻译，译文直接覆盖在原文所在位置，保持原有排版；支持原文/译文一键切换、复制原文、复制译文，`Esc` 或关闭按钮退出。
- 覆盖样式自动适应画面：按周边背景取色遮盖原文，并根据背景明暗自动选择译文颜色与字号。
- 翻译服务与目标语言跟随设置中的当前选择，逐段并发翻译。

## 测试提示

这是测试版本。截屏翻译的取色、字号与段落聚合效果会根据反馈继续调优；识别效果受画面清晰度与背景复杂度影响。原有“截图翻译”（截图工具栏内）保持不变。
