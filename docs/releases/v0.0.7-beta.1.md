# Polyglance v0.0.7-beta.1

Polyglance v0.0.7-beta.1 带来了全面的**截图标注交互重构**、**丰富箭头与线条样式体系**、**工具栏全局拖拽移动**以及双端菜单智能停靠与稳定性优化。

## 核心新特性与优化

- **全新截图标注二级工具栏**：
  - 针对画笔、线条、箭头、矩形/椭圆、文字、序号、马赛克等标注工具提供专用二级属性栏。
  - 支持颜色调色盘、线宽数字气泡微调滑块与滚轮调节、文字粗斜体及边框等属性即时切换。
- **丰富箭头与虚实线条样式**：
  - 支持 9 种箭头与端点样式（单向/双向细粗箭头、空心/实心大箭头、T 型端点线等），默认采用左小右大空心箭头。
  - 支持 4 种线条虚实样式（实线、长虚线、点线、点划线）。
- **工具栏拖拽移动与协同跟随**：
  - 一级主工具栏支持鼠标拖拽整体平移，二级菜单及下拉层实时跟随，并自动约束在屏幕可视区域内。
- **智能停靠布局与零抖动优化**：
  - 智能感知屏幕可视边界：选框外部空间充足时位于下方或上方；上下空间不足时自适应停靠选框内部。
  - 修复 Windows 二级菜单展开时由于尺寸与边距计算导致的主菜单像素级跳变，实现二级菜单与一级菜单严格左对齐并保持绝对位置零偏移。
