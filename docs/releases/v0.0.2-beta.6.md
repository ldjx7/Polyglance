# Polyglance v0.0.2-beta.6

本次 Beta 新增 AI 翻译流式输出开关。

## 更新内容

- 设置 → 翻译服务：选择“免费 AI 翻译”或“自定义 AI”时新增“流式输出译文”开关（默认开启）。开启后 AI 译文逐字显示；关闭后等待完整译文一次性显示。
- Google 与 Microsoft 免费翻译始终一次性返回完整结果，不受该开关影响。
- 更新 README 中的默认翻译服务说明（自 v0.0.2-beta.4 起新安装默认使用 Microsoft 免费翻译）。

## 测试提示

这是测试版本。若从 v0.0.2-beta.5 升级，已授予的系统权限在自动更新后无需重新授权。
