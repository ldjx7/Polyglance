# Polyglance v0.0.9-beta.1

Polyglance v0.0.9-beta.1 聚焦于贴图功能的交互体验优化与核心算法重构，包括快捷键复制与反馈、方向键微调位置、大幅放宽缩放限制至 1%、100% 自动吸附，以及彻底修复 macOS 端的缩放手感与极小缩放下的变形失真问题。

## 新增特性与优化

### 1. 贴图快捷键复制与视觉反馈
- **快捷键支持**：选中贴图后支持直接使用键盘快捷键（macOS `⌘C` / Windows `Ctrl+C`）复制当前带标注的合成图像至系统剪贴板。
- **瞬态微提示**：复制成功后，贴图窗口右上角弹出 1 秒「已复制」微提示，并在淡出后自动隐藏，不破坏界面整洁。
- **界面精简**：移除 macOS 端贴图在鼠标悬停时显示的右上角关闭按钮，保持双端视觉体验纯粹一致。

### 2. 方向键微调贴图位置
- 选中贴图后，支持通过键盘方向键（↑ / ↓ / ← / →）微调贴图窗口位置，单次步进 1px；按住 `Shift` 键可快速步进 10px。
- 移动过程实时接入多屏安全边界检测，确保贴图始终位于屏幕可见区域内。

### 3. 缩放范围放宽与 100% 吸附
- **放宽缩放倍率**：贴图缩放下限放宽至 1%（0.01x），上限支持至 800%（8.0x），满足极端缩小纵览与细节放大需求。
- **100% 智能吸附**：无论如何缩放，缩放跨越 100% 阈值附近时均会自动精准吸附至 100%，方便随时还原原始尺寸。

### 4. macOS 缩放算法重构与抗变形修复
- **缩放手感对齐**：重构 macOS 端的滚轮缩放计算逻辑，告别原先由系统滚轮加速度导致的指数级失控暴涨，全面对齐 Windows 端的平滑离散步进机制（常规 1.1x / 1/1.1x，Option 微调 1.025x / 1/1.025x）。
- **彻底根除变形失真**：
  - 针对此前 macOS 端缩放到极小尺寸时因像素舍入误差累加导致窗口长宽比失真、回到 100% 后依然变形的问题进行底层重构。
  - 维护独立缩放比例状态，窗口几何尺寸直接基于原始图像尺寸实时计算，彻底阻断误差累积。
  - 视图绘制与标注层增加等比例安全自适应（Aspect Fit）保护，杜绝任何挤压畸变。

## 下载与安装

- macOS 用户推荐下载 `Polyglance-0.0.9-beta.1-macOS.dmg`，已安装用户可通过菜单栏「检查更新…」在线升级。
- Windows 用户推荐下载 `Polyglance-0.0.9-beta.1-Windows-x64-Setup.exe`，或使用便携版 `Polyglance-0.0.9-beta.1-Windows-x64-Portable.zip`。
- Windows 应用商店测试用户可下载 `Polyglance-0.0.9-beta.1-Windows-x64.msix`。
