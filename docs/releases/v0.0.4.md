# Polyglance v0.0.4

这是 Polyglance 的第一个正式版本。0.0.4 把项目从「一个 macOS 工具」变成了双端产品：Windows 客户端首次发布，两端共用同一套 Rust 核心，内置免费 AI 翻译迁移到 Polyglance 官方服务，官网同步上线。

## Windows 客户端首次发布

- 完整的 Windows 客户端（.NET 9 WPF），覆盖截图、贴图、标注、取色、OCR、长截图、录屏和划词翻译，与 macOS 保持同一套交互。
- 截图标注、取色放大镜、长截图拼接的行为在双端对齐，同样的操作在两个系统上得到同样的结果。
- 提供 x64 便携版 ZIP 和安装版 EXE 两种分发方式。
- 修复升级或便携版换目录后「开机自启」被误判为关闭：现在会识别旧版注册项并迁移到当前路径。
- 修复划词翻译读到剪贴板旧内容的问题。
- 修复快捷键录制与热键注册失效。
- 更新检查改为托盘通知与内联进度，不再弹出打断操作的模态框。

## 免费 AI 翻译改为官方服务

- 客户端不再打包上游 API Key、模型和 Prompt，只向 Polyglance 官方接口发送原文与语言信息。
- 服务端固定翻译用途、模型与 Prompt，并加入请求格式校验、长度限制、分级计费额度和匿名调用频率限制，无法当作通用 AI 接口使用。
- 接入 Gemini、Groq、SiliconFlow、OpenRouter 多服务商，按权重负载均衡并在故障时自动切换。
- 支持流式返回译文，同时过滤上游模型与服务商元数据。
- 放宽了原本会误判正常使用为超额的频率限制。
- 构建两端客户端不再需要注入免费 AI 的 API Key。

## 跨屏截图与贴图

- 多显示器下截图会合成一张完整的虚拟桌面位图，框选可以跨越屏幕边界。
- 拖动到副屏时，副屏上会实时显示当前选区的边界与控制点，不再需要盲选。
- 贴图现在严格贴在所选像素的原位，并采用选区的点尺寸而不是 Retina 物理像素，全宽截图贴出来仍是全宽。
- 消除了 macOS 上贴图出现瞬间的闪烁：截图遮罩会一直保留到贴图窗口的第一帧真正上屏。
- 贴图创建后即为选中态，边框与投影明确区分当前操作的是哪一张。

## 截图、录屏与取色

- 修复快速滚动时长截图拼接出重复内容。
- 长截图不再把选区自身的界面元素录进画面；Windows 端会明确提示被跳过的帧。
- 录屏的默认格式、帧率和倒计时会被保存并应用到工具栏；倒计时现在真正生效。移除了尚未实现却出现在设置里的 WebM 选项。
- 放大镜在两端统一显示色块、完整 HEX/RGB 色值、像素坐标和快捷键提示；修复屏幕边缘取色时的越界与准星偏移，保证准星所指的像素就是复制到的色值。
- macOS 部署目标下调到 macOS 14，覆盖更多设备；mp4 音频混流按 macOS 15 做了版本保护。

## 官网

- 官网上线，使用自定义域名，更新日志通过 GitHub API 自动同步。
- 下载入口自动识别访问者的操作系统，并根据 Release 中真实存在的资产跳转，平台构建缺失时不会给出必然 404 的链接。
- 展示真实下载计数与历史版本列表。

## 下载

本次发布提供 macOS ZIP / DMG，以及 Windows x64 便携版 ZIP 和安装版 EXE。
