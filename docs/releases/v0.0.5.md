# Polyglance v0.0.5

Polyglance v0.0.5 带来了全新的**二维码/条形码多码识别与结构化交互**、**官方免费 AI 翻译智能分层与极速优化**，以及双端体验的全面打磨。

## 二维码与条形码智能识别（双端支持）

- **多码自动检测与原位标记**：截图完成后自动扫描选区内的所有二维码与条形码（支持 QR Code、Code 128、EAN-13、Data Matrix、Aztec、PDF417 等格式），在每个条码中心绘制交互徽标，悬浮或点击即可查看解析结果。
- **结构化内容识别与一键操作**：
  - **WiFi 二维码**：智能解析 WiFi 名称（SSID）、加密方式与密码，提供一键复制密码与网络连接。
  - **OTP 两步验证**：识别 `otpauth://` 协议密钥，支持一键复制与快捷导入密码管理器。
  - **网页链接**：一键在默认浏览器中打开或复制链接。
  - **通用文本与条形码**：支持长文本一键展开与快捷复制。
- **跨平台技术架构**：
  - macOS 端采用系统原生 Vision 框架，提供零依赖的高性能实时识别。
  - Windows 端基于轻量高效的 ZXing 引擎实现纯本地毫秒级解析。
  - 针对 Windows 10 系统适配了图标字体回退链（`Segoe Fluent Icons, Segoe MDL2 Assets`），彻底解决 Win10 下 WiFi 图标显示为豆腐块的问题。

## 免费 AI 翻译双层调度与毫秒级极速优化

- **重构双层候选调度架构**：引入 **Tier 1 (优选通道)** 与 **Tier 2 (保底通道)** 智能故障转移机制，兼顾极速响应与全天候高可用性。
- **默认优先命中极速专线**：
  - 🥇 **首选接入**：硅基流动（SiliconFlow）搭载的腾讯 **Hunyuan-MT-7B 专用翻译微调模型**，国内节点直连，实测平均响应仅 **0.6 秒**，且支持 1000 RPM 高并发。
  - 🥈 **次优专线**：Groq 硬件级 LPU 超高速推理通道（0.6 秒）。
  - 🥉 **深度保底**：Google Gemini 与 OpenRouter 自动容灾兜底。
- **思维链自动清洗**：服务端新增思考标签（`<think>...</think>` / `<thought>...</thought>`）流式与非流式实时过滤，杜绝推理模型思维过程污染译文。

## 客户端细节打磨与体验优化

- 工具栏新增二维码识别快捷入口与状态联动。
- 完善双端单元测试套件（macOS Swift Tests & Windows xUnit）。
- 双端版本号与品牌信息统一对齐至 `v0.0.5`。
