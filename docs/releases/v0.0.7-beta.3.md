# Polyglance v0.0.7-beta.3

Polyglance v0.0.7-beta.3 带来了双端工具栏自定义排序、全新矢量图标升级、Windows 设置面板交互重构与动画支持，以及 macOS 权限引导与主窗口交互优化。

## 新增特性与优化

- **工具栏自定义与全新默认排序**：
  - 双端均支持自定义截图与录屏工具栏按钮排序和启用状态。
  - 统一默认排布顺序：画笔 -> 线条 -> 箭头 -> 椭圆 -> 矩形 -> 文字 -> 马赛克 -> 序号 -> 撤销 -> 重做 -> 长截图 -> 录屏 -> 文字识别 -> 识别并翻译 -> 二维码 -> 保存 -> 取消 -> 贴图 -> 复制。
  - 设置面板提供拖拽排序与启用功能储备池卡片。

- **双端图标矢量化升级**：
  - 重新设计双端工具栏与设置面板的全部矢量图形路径，提供更为现代精致的视觉质感。

- **Windows 设置面板交互优化**：
  - 生效工具栏胶囊支持平滑的实时拖拽位移与透明度动态反馈。
  - 隐藏预览胶囊下方多余的横线，移除角标改为鼠标悬停显示。
  - 扩展设置窗口整体宽度与内容区域布局，确保 19 个按钮在全选启用时完整居中展示，杜绝卡片文字截断。

- **macOS 权限引导与窗口交互修复**：
  - 修复屏幕录制与辅助功能权限缺失时静默退出的问题，增加快捷前往系统设置隐私面板的弹窗引导。
  - 确保主翻译窗口在各类快捷调用场景下正确激活并置顶显示。
