# Polyglance v0.1.5-beta.2

本次为剪贴板历史功能的第二个公开测试版，主要增加轻量级快速选择浮窗，分流日常即时选用与完整历史管理，并统一鼠标、键盘修饰键动作与循环选择规则。

## 新增功能与交互优化

- **快速选择浮窗与管理窗口分流**：
  - 呼出快捷键与菜单默认打开快速选择浮窗，聚焦搜索框，支持键盘导航与单击选用，选用后或点击窗口外部自动关闭。
  - 快速浮窗可通过 Command+M 或点击管理历史按钮切换至完整管理窗口，保留当前搜索查询、条目选择与原目标应用；管理窗口继续支持多选、内容编辑、本地 OCR 识别、二维码解析、贴图及数据备份。
- **动作表与修饰键规则统一**：
  - 自动粘贴关闭时：单击、Enter 或数字快捷键执行复制并关闭；Option 组合键执行自动粘贴并关闭；Option+Shift 组合键执行纯文本粘贴。
  - 自动粘贴开启时：单击、Enter 或数字快捷键执行自动粘贴并关闭；Option 组合键切换为仅复制；Command+Shift 组合键执行纯文本粘贴。
- **数字快捷键与固定项编号优化**：
  - 快速选择浮窗数字编号仅计算已加载的普通历史条目，不占用固定项位置；管理窗口按列表前九项依次编号。
  - 中文输入法候选词确认期间拦截导航与选用动作，避免候选确认与条目选用冲突。
- **循环选择逻辑增强**：
  - 开启循环选择后，首次呼出展开浮窗，重复按呼出主键向下移动选择，释放全部修饰键后执行确认，支持更平滑的单手循环操作。
- **设置入口与状态同步**：
  - 剪贴板历史总开关迁移至设置 > 通用，修改立即持久化保存；管理窗口设置齿轮保留容量、过期天数、排除规则等高级配置，保存时不再覆盖通用设置中的最新开关状态。

## 开始测试

1. macOS 下载 `Polyglance-0.1.5-beta.2-macOS.dmg`，安装后在设置 > 通用中开启剪贴板历史。
2. 在快捷键设置中配置剪贴板历史呼出快捷键（建议设为 Command+Shift+V）。
3. 复制文本、富文本或图片后呼出快速浮窗，测试快速搜索、键盘与鼠标选用、Command+M 切换管理窗口及跨应用自动粘贴。
4. 实机测试参考 [macOS 实机验收表](https://github.com/ldjx7/Polyglance/blob/v0.1.5-beta.2/docs/剪贴板macOS实机验收.md)；遇到异常请反馈具体系统版本、目标应用名称与复现步骤。

## 测试范围与已知限制

- 本次主要更新 macOS 客户端剪贴板交互；Windows 客户端本期继续沿用现有版本，等待后续 Rust 与 Slint 界面重构分支接入。
- 自动粘贴与原目标应用恢复依赖 macOS 辅助功能权限；首次使用请按系统提示授权。
- 本版本标记为 Pre-release，不替换 GitHub 正式版发布通道。
