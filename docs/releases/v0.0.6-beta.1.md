# Polyglance v0.0.6-beta.1

Polyglance v0.0.6-beta.1 带来了全新的**测试版与正式版更新通道隔离机制**、**智能免打扰主动推送**以及双端更新界面的视觉重构。

## 更新通道隔离与测试版尝鲜

- **正式版与测试版通道隔离**：
  - 偏好设置「关于」页新增 **「接收测试版更新 (Beta Channel)」** 切换开关。
  - 正式版构建默认仅接收经过充分验证的稳定版本，避免测试阶段的变动影响日常使用。
  - 测试版与开发版构建默认开启尝鲜通道，第一时间体验最新特性。
- **指定版本跳过**：
  - Windows 端检测到新版本后，支持点击 **「跳过此版本」**，在该版本被更高版本替代前不再弹窗打扰。
- **版本类型胶囊徽标**：
  - 设置页面清晰展示当前构建类型（`[正式版 🟢]` / `[Beta 尝鲜 🧪]`）。

## 后台智能静默推送（免手动检查）

- **双端后台主动轮询**：
  - Windows 端启动 10 秒后静默发起首轮检查，运行期间每 6 小时静默轮询一次。
  - macOS 端完整集成 Sparkle 2 原生静默更新调度。
- **托盘菜单与系统通知直观联动**：
  - 发现新版本时，自动弹出系统原生 Toast/通知气泡。
  - 托盘右键菜单顶层动态插入带醒目标识的快捷更新项（`🚀 发现新版本 / 🧪 发现新测试版`），点击一键直达。

## 下载与测试

本次发布为测试预览版本（Pre-release），供尝鲜用户体验并反馈新功能。
