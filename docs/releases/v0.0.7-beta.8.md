# Polyglance v0.0.7-beta.8

Polyglance v0.0.7-beta.8 带来了全新的品牌视觉体系，并重构统一了双端内嵌式零打扰应用更新交互体验。

## 新增特性与优化

- **全新的品牌视觉与应用图标**：
  - 更新品牌图标为截图取景框与双语卡片设计，优化全平台应用图标（macOS .icns、Windows .ico、Web 图标）。
  - macOS 菜单栏适配单色矢量自适应图标，根据系统深浅色与选中状态自动适配。
  - 优化设置页侧边栏顶部品牌 Logo 呈现尺寸与排版，图标展示饱满清晰。

- **双端内嵌式零打扰更新交互**：
  - 废弃独立模态弹窗与系统气泡提示，更新全流程统一收敛在设置页「关于」选项卡中。
  - 解耦更新下载、校验与重启过程，更新包准备完成后进入就绪状态，支持「稍后重启」与「立即重启应用」，不再强制中断用户工作。
  - Windows 托盘右键菜单「检查更新…」直接唤起设置页并就地检查更新。
  - 完善更新下载进度与状态展示，清晰显示已下载大小、总量与百分比。
