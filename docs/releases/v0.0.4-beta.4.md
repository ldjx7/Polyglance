# Polyglance v0.0.4-beta.4

本次 Beta 统一并精简 macOS 与 Windows 的版本号展示，便于验证跨版本更新流程。

## 修复

- Windows 托盘提示、托盘菜单和设置页现在只显示 `v0.0.4-beta.4`。
- 移除 Windows 版本号中由 .NET 自动附加的 Git 提交哈希，例如不再显示 `+30bf6a5...`。
- macOS 菜单栏和设置页不再把产品名称、内部构建号拼入版本字段。
- 两个平台统一采用 `v<语义版本>` 的用户可见格式；内部构建号仍用于更新比较和产物追踪。

## 下载产物

- macOS：ZIP、DMG。
- Windows x64：免安装便携版 ZIP、安装版 EXE。

本次改动不影响应用名称、安装包文件名、用户设置或系统授权。
