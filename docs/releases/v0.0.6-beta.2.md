# Polyglance v0.0.6-beta.2

Polyglance v0.0.6-beta.2 修复了测试通道更新检索机制以及官网免费 AI 翻译单词释义冗余问题。

## 核心修复与优化

- **测试更新源检索优化**：
  - 修复 Windows 与 macOS 端在开启测试通道后因 GitHub `/releases/latest/` 重定向机制导致无法检测到最新 Beta 版本的问题。
  - 客户端在启用「接收测试版更新」时，优先通过 GitHub Releases API 获取最新的 Pre-release 描述文件与安装包。
- **免费 AI 翻译规范输出**：
  - 优化服务端 Hunyuan-MT 专用翻译模型的提示词，杜绝单单词或计算机术语输出百科释义/词条定义的现象，严格保持精准直译。
- **自动化发布工作流优化**：
  - 完善 GitHub Actions Pre-release 状态判断，确保测试版本自动化发布链路通畅。

## 下载与测试

本次发布为测试预览版本（Pre-release），供尝鲜用户体验并反馈新功能。
