# Polyglance v0.0.8-beta.1

Polyglance v0.0.8-beta.1 带来了全新的独立「截图与录屏」设置模块、Mac 工具栏动态响应式缩放、翻译窗口双端交互增强（全局与独立重新翻译、划词直接替换），以及多项细节体验优化。

## 新增特性与优化

- **新增独立的「截图与录屏」设置面板（双端对齐）**：
  - 梳理并重构设置页导航体系，新增「截图与录屏」专属面板，集中管理截图历史自动归档、录屏导出格式（MP4 / GIF）、帧率、倒计时、音频录制偏好与存储目录。
  - 「工具栏」设置页全面精简专精，专注于截图工具栏图标排布、拖拽排序与功能储备池开关。

- **Mac 工具栏动态响应式缩放**：
  - 工具栏设置页面支持实时监听窗口尺寸，随鼠标拖拽放大窗口自适应等比缩放生效胶囊栏与功能储备池卡片尺寸、图标与字号，充分利用大窗空间。
  - 窗口缩小时平滑回退，结合动态字号自适应机制杜绝任何文字截断。

- **翻译窗口交互与重试体验升级**：
  - 翻译窗口新增全局「重新翻译」功能（支持快捷键 ⌘R / Ctrl+R），所有已启用服务一键重试。
  - 独立翻译卡片新增专属「重新翻译」按钮，可在单个服务网络异常或失败时单独重试。
  - 修复 macOS 翻译窗口原文输入框快捷键操作（全选、撤销等）失效问题。

- **Windows 划词翻译与替换增强**：
  - 优化划词翻译流程，支持将译文一键替换回当前光标选中的文本。
  - 支持离线模型与本地数据目录的统一管理与存储路径自定义。

- **设置窗口交互优化**：
  - 调整 Mac 设置窗口尺寸至 900 × 580，提供更加宽敞舒展的布局体验。
  - 当设置窗口已打开时，再次唤起直接将窗口置顶激活，避免重复居中移动窗口。
