# macOS 开发说明

## 环境

- macOS 14 或更高版本（当前应用部署目标）
- Rust 1.97 或更高版本
- Swift 6.2 / Xcode Command Line Tools

## 构建 Rust 与 Swift 绑定

```bash
./scripts/build-macos-core.sh
```

脚本会：

1. 构建 `translator-uniffi` Rust 静态库。
2. 运行 UniFFI 生成 Swift binding 和 C header。
3. 把生成内容放入 `apps/macos/Generated`。
4. 把静态库放入 `apps/macos/Libraries`。

生成目录不进入 Git，切换机器或清理后需要重新运行脚本。

## 运行测试

```bash
cargo test --workspace
cd apps/macos
swift test
```

## 构建可双击应用

```bash
./scripts/build-macos-app.sh
```

开发构建会先关闭当前项目目录下正在运行的应用，在签名完成后自动清除该 Bundle ID 的“辅助功能”和“屏幕录制”授权，但不会自动启动。随后手动运行 `dist/Polyglance.app`，并在系统设置中重新添加权限即可。这样可以避免临时签名变化后，系统权限列表仍显示旧条目已启用。

如果是 CI、正式签名构建，或者希望保留现有授权，请使用：

```bash
./scripts/build-macos-app.sh --preserve-permissions
```

产物位于：

```text
dist/Polyglance.app
```

当前使用本机临时签名，适合开发测试。正式发布需要 Apple Developer ID 签名和公证。

临时签名的代码身份会随构建变化。重新构建后，如果辅助功能或屏幕录制权限看似开启但实际无效，需要删除旧权限记录并重新授权；长期开发应改用稳定的代码签名证书。

## 首次使用

1. 新安装默认使用 Google 免费翻译，不需要 API Key。
2. 如需 Google 翻译，在“设置 → 翻译服务”中选择“Google 免费翻译”，无需 API Key。它使用 Google 的旧版免费接口，可能受网络、限流和接口变更影响。
3. Microsoft 免费翻译同样无需 API Key，使用 Microsoft Edge 的免费翻译接口，可能受网络、限流和接口变更影响。
4. 正式发布构建可提供“免费 AI 翻译”，用户无需填写 Key；服务凭据同样只在构建阶段注入。该选项不会在配置缺失时静默改用其他服务。
5. 如需 DeepSeek、OpenAI 或其他兼容服务，主动选择“自定义 AI”，再填写 endpoint、API Key 和模型。
6. 点击“请求权限”，在系统设置中允许辅助功能权限。
7. 点击“请求屏幕权限”，在系统设置中允许屏幕录制权限，然后重启应用。
8. 在任意应用中选中文字，按默认快捷键 `Option+D`。

Google、Microsoft、自定义 AI 和免费 AI 都是第三方联网服务，不应传输敏感内容。只有自定义 AI 的用户 Key 存放在 macOS Keychain；内置服务不会要求用户填写凭据。应用不会在翻译失败后静默切换提供商。

## 构建内置免费 AI 翻译

本地或 CI 构建可通过环境变量注入 OpenRouter 免费模型配置，不在源码中硬编码：

```bash
POLYGLANCE_FREE_AI_API_KEY="..." \
POLYGLANCE_FREE_AI_ENDPOINT="https://openrouter.ai/api/v1" \
POLYGLANCE_FREE_AI_MODEL="openrouter/free" \
./scripts/build-macos-app.sh
```

也可以复制仓库根目录的 `.env.example` 为被 Git 忽略的 `.env.local`，填写后执行：

```bash
set -a
source .env.local
set +a
./scripts/build-macos-app.sh
```

`POLYGLANCE_FREE_AI_ENDPOINT` 和 `POLYGLANCE_FREE_AI_MODEL` 可省略并使用上面的默认值。构建脚本不会输出 Key；GitHub Release 工作流从 `FREE_AI_OPENROUTER_API_KEY` Secret 注入。

重要：任何直接放进桌面应用的 Key 都可以从最终 `.app` 中提取。公开发布时必须给该 Key 配置独立额度、模型限制、速率限制和隐私策略，不得与管理账号或付费高额度 Key 共用。更可靠的生产方案是让应用调用自己的限流代理，由代理在服务端持有 OpenRouter Key。

如果应用无法通过 Accessibility API 直接获取选区，会自动模拟一次 `Command+C`，读取本次复制的文本，并在剪贴板没有被其他操作再次修改时恢复原内容。不会把原有的旧剪贴板文本误当成选区。

## 快捷键

| 默认快捷键 | 功能 |
| --- | --- |
| `Option+1` | 打开高分辨率截图工具，框选后可标记、复制或置顶 |
| `Option+2` | 将剪贴板中的图片生成贴图 |
| `Option+3` | 框选区域并进入纵向长截图 |
| `Option+4` | 框选区域并进入 MP4/GIF 录屏准备；准备态再次按下开始，录制中再次按下停止 |
| `Option+5` | 恢复最近关闭的贴图（普通图片或 OCR 翻译贴图） |
| `Option+D` | 读取当前选区并立即翻译 |
| `Option+Shift+D` | 只读取当前选区，打开窗口后可先编辑 |
| `Command+Return` | 翻译输入框中的内容 |
| `Command+Shift+C` | 复制译文 |
| `Command+K` | 清空原文、译文和错误，并聚焦原文输入框 |

上表中的七个全局动作（截图、贴图、长截图、录屏、恢复贴图和两个取词动作）都可以在“设置 → 全局快捷键”中修改。点击快捷键框后直接按下新组合，按 `Esc` 取消录制；每个组合至少需要包含 `Command`、`Option` 或 `Control`，且不能互相重复。若组合已被系统或其他应用占用，保存会失败并保留原来的快捷键。

完成截图选区后还可以使用以下局部操作：

| 操作 | 功能 |
| --- | --- |
| `方向键` | 沿对应方向移动 1 个输出像素 |
| `Option+方向键` | 沿对应方向移动 10 个输出像素 |
| `Shift+方向键` | 将对应边向内收缩 1 个输出像素 |
| `Command+方向键` | 将对应边向外扩大 1 个输出像素 |
| `Command+Z` | 撤销最近一次标注 |
| `Command+Shift+Z` | 重做标注 |
| `C` | 在尚未完成选区时复制放大镜当前颜色 |
| `Shift+C` | 在 HEX 与 RGB 取色格式间切换 |
| `Return` | 复制当前选区并结束截图 |
| `Esc` | 直接取消本次截图 |
| `Shift+C`（已选区） | 对当前截图选区 OCR，并直接复制全部识别文字 |
| `Option+Q`（已选区） | OCR 当前截图选区并生成翻译贴图 |
| `G`（已选区） | 以当前截图选区进入录屏准备态 |

## 截图与贴图

按 `Option+1` 后会立即进入截图输入状态，在鼠标当前所在的显示器上直接拖动框选区域，无需先点击激活。框选期间可按 `Esc` 取消；完成选区后右键先回到截图初始状态，再次右键才退出。选区前会显示 Retina 像素放大镜、坐标和 HEX/RGB 颜色。松开鼠标后十字光标会恢复为箭头，并显示仅使用系统图标的操作工具条；按钮悬浮提示只显示动作名称，并保留辅助功能标签。工具条支持画笔、矩形、椭圆、箭头、文字、自由涂抹式马赛克、撤销、重做、复制、直接保存 PNG、置顶贴图、OCR、OCR 翻译、长截图、录屏和取消；不会再默认贴图。窄屏自动切换为双排图标。Retina 显示器按物理像素采集，工具条中的尺寸标签显示最终输出像素，方向键也按输出像素精调而不是按逻辑点粗调。

OCR 使用 macOS Vision 在本机识别。点击“OCR”会在原选区位置打开带原图的文字贴图：空闲时不显示密集识别框，按阅读顺序正向或反向拖选字符或单击文字后，才在选区旁显示“复制 / 翻译”快捷动作；也可把已选文字直接拖入其他应用。`Command+C` 只复制当前选中内容，`Shift+C` 复制全文。第一次按 `Esc` 退出文字选择但保留贴图，退出后右键菜单和左键双击关闭仍然有效；第二次按 `Esc` 或 `Command+W` 也可关闭。`Option+拖动` 可移动贴图。OCR 文字贴图和普通/翻译贴图共用隐藏、显示、关闭、销毁及恢复历史。点击“OCR 翻译”或文字选区旁的“翻译”时，只有识别后的文本会交给当前翻译服务，截图图像本身不会上传。翻译结果以类似有道截图翻译的轻量结果卡显示在截图选区下方（空间不足则显示在上方），默认同时展示原文和译文，也可切回原图或仅看原文，并复制当前文字状态。

长截图与录屏基础流程：

- `Option+3` 框选后会直接进入纵向长截图采集并立即记录首帧，不再要求第二次点击“开始”。区域框进入红色采集态并让鼠标穿透，控制条附着在选区下方，只显示贴图、复制和关闭图标；复制或贴图会自动完成当前拼接、执行对应动作并退出，关闭则取消；不滚动时复制/贴图就是当前框选内容。
- 长截图支持纵向向上或向下的双向重叠拼接，并容忍滚动区域内少量固定表头；回滚到已经捕获的画面不会重复添加。缩略图不显示帧数或输出尺寸，也不预留固定大画布，而是随当前拼接内容按比例增长，并用绿色框标出当前视口位置。系统同时限制有效帧数、输出高度、总像素和工作内存；未滚动产生的重复画面不会消耗有效帧上限，滚动步幅过大或画面缺乏可靠重叠时会给出错误。横向拼接代码暂时保留为实验能力，但产品入口已经隐藏。
- `Option+4` 框选后先进入蓝框准备态，区域仍可移动并从八个方向缩放；贴框工具条可选择 MP4/GIF、三档质量、帧率、0/3/5 秒倒计时、系统声音、麦克风和鼠标。开始后边框变红，暂停时变橙；可暂停/继续或停止。准备态再次按录屏全局快捷键会开始录制，倒计时期间再次按下会取消倒计时，录制或暂停期间再次按下会停止并进入回放。
- 普通录制停止后进入回放窗口，可播放/暂停、保存、快速保存、复制文件、重新录制或关闭。复制会先把成片持久化到默认目录，因此关闭回放后剪贴板文件仍有效。设置中的“点击保存时询问保存位置”只控制普通“保存”；快速保存和复制始终使用默认目录，快速保存不会打开 Finder 打断当前工作。未选择目录时使用用户的“影片”文件夹，重名会自动追加序号。
- 录制中关闭工具条、关闭或重新录制尚未保存的回放、以及带未保存录屏退出应用时，都会提供“保存 / 丢弃 / 取消”；选择取消会留在当前状态。普通保存覆盖已有文件时先写同目录临时文件，再原子替换，写入失败不会提前删除原文件。
- “设置 → 区域录屏”可保存默认格式、质量、显式帧率、0/3/5 秒延时、保存策略、默认目录、系统声音、麦克风和鼠标指针。MP4 可选 5/16/24/30/60 FPS；GIF 当前提供 5/16 FPS、自动关闭音轨，并继续受三档质量的最长边、时长和帧数上限约束。

当前三档录屏参数如下（超过最长边时等比例缩小）：

| 质量 | MP4 | GIF |
| --- | --- | --- |
| 体积优先 | 初始默认 24 FPS，最长边 1920 px | 可选 5/16 FPS，最长边 960 px，最长 90 秒/720 帧 |
| 标准 | 初始默认 30 FPS，最长边 2560 px | 可选 5/16 FPS，最长边 1280 px，最长 60 秒/720 帧 |
| 高质量 | 初始默认 60 FPS，最长边 3840 px | 可选 5/16 FPS，最长边 1600 px，最长 45 秒/675 帧 |

- 开启麦克风时 macOS 会单独请求麦克风权限；开发构建默认会和辅助功能、屏幕录制权限一起重置。

贴图支持：

- 拖动图片移动窗口。
- 拖动窗口边缘、使用触控板捏合，或使用鼠标滚轮以指针位置为锚点缩放。
- `Option+滚轮` 精细缩放，`Command+滚轮` 调整透明度。
- 中键恢复贴图初始尺寸，并保持窗口中心不变。
- 右键锁定/解锁贴图；锁定后禁止移动和缩放。
- 右键可在普通窗口层级和保持置顶之间切换。
- 悬停后点击右上角或双击关闭；普通关闭会进入进程内历史，“彻底销毁”不会进入历史。
- 普通图片贴图右键可复制图片、另存为 PNG；OCR 翻译贴图可显示原图/译文并复制选中译文。普通图片、OCR 文字和翻译贴图均可通过右键“标注”或空格重新进入编辑，标注工具条作为独立附着面板显示在图片下方；支持画笔、矩形、椭圆、箭头、文字、自由涂抹马赛克和撤销/重做。复制、保存和关闭历史使用合成后的标注结果。各类贴图也都支持双击关闭、透明度、锁定、置顶、关闭/销毁及批量操作。
- 菜单栏也提供恢复、隐藏/显示、关闭/销毁全部动作；默认 `Option+5` 按真实关闭顺序恢复最近关闭的普通图片或 OCR 翻译贴图。
- 两类贴图共用一个进程内历史，默认最多保留 20 张、估算内存上限约 256 MiB，超限淘汰最早记录。恢复会保留窗口位置/尺寸、透明度、锁定、置顶状态和翻译贴图的原图/译文显示模式。“彻底销毁”不入历史；应用退出后历史不落盘，图片也不会自动上传。

## 截图与贴图人工验收

构建后建议按以下顺序做一次真实环境验收：

1. 在 Retina 屏幕截图，确认尺寸标签、复制 PNG 和保存 PNG 的物理像素一致。
2. 在双屏环境触发截图，确认鼠标所在屏保持明亮、其他屏变暗，且副屏右键遵循相同的逐级回退语义。
3. 分别悬停普通窗口和控件，确认窗口候选立即出现、辅助功能元素稍后细化；再自由拖动一次选区。
4. 验证 `Esc` 直接取消，选区完成后的右键先回初始状态，再次右键退出。
5. 分别执行复制、保存、贴图和取消；保存面板取消时不应生成文件。
6. 用画笔、矩形、椭圆、箭头、文字和马赛克各操作一次，撤销/重做后比较屏幕预览与最终 PNG。
7. 使用方向键、Option/Shift/Command 组合键微调选区，确认 Retina 屏每个标准步长对应 1 个输出像素。
8. 使用 `Option+2` 测试有效图片剪贴板和无图片剪贴板两条路径。
9. 对贴图验证滚轮锚点缩放、Option 精细缩放、Command 透明度、锁定/解锁、置顶切换、中键复位和双击关闭。
10. 用中英文混排截图验证 OCR 连续拖选、反向拖选、单字点击、`Command+C` 只复制选中、`Shift+C` 复制全文、第一次 `Esc` 退选择/第二次关闭；再执行 OCR 翻译，确认可切换原图/原文/译文，且只有识别文本进入网络请求。
11. 在网页中框选滚动内容，分别向下、向上滚动，并验证下滚后回滚不会重复画面。点击复制或贴图后确认自动结束、接缝顺序正确且工具界面退出。
12. 分别验证蓝框区域八向编辑、0/3/5 秒倒计时和全局快捷键开始/取消倒计时/停止；录制无声、系统声音和麦克风 MP4，确认红框录制、橙框暂停且成片不保留暂停空段；再录制短 GIF，确认无音轨、安全上限和回放中的保存/快存/复制/重录/关闭。
13. 交替创建并关闭普通图片与 OCR 翻译贴图，验证批量隐藏/显示/关闭同时作用于两类贴图，`Option+5` 按真实关闭顺序恢复，彻底销毁不可恢复，且锁定/透明度/置顶/原图或译文模式能随恢复保留。

## 当前限制

- 只生成当前机器架构的本地开发产物，最低支持 macOS 14。
- 长截图当前只开放纵向手动滚动，不包含自动滚动、端部裁剪和中间区块删除；横向入口暂时隐藏。
- 录屏当前输出 MP4 和 GIF；回放只提供整段预览与结果动作，不包含时间轴剪辑、速度调整、MOV/WebM/APNG/WebP、摄像头、键鼠展示或录制中标注。
- OCR 当前支持字符级选择与拖出文字，但不包含表格/公式识别和复杂多栏/竖排版面重建。
- 普通图片与 OCR 翻译贴图已进入统一恢复历史，但历史只在当前进程内保留，尚不支持应用重启后恢复。
- 标注样式选择和既有元素的二次选中编辑尚未实现；贴图内重新标注已经支持。
- 已接入 Sparkle 2 自动更新和 GitHub tag 发布工作流；公开分发仍需在 GitHub Secrets 中配置 Developer ID 与 Apple 公证凭据。
