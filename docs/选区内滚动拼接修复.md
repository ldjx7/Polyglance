# 选区内部滚动无法拼接

基于 v0.1.5-beta.2。用户确认选区内内容实际已经滚动，但长截图没有继续增长。

macOS 为小选区向上下额外采集最多 400 pt 的画面，帮助判断快速滚动的距离。旧算法对整个采集帧估计位移。如果选区是页面中的独立滚动容器，外围画面保持静止，外围像素就会干扰选区内容的匹配。两项回归用例在旧实现中均返回 NoReliableVerticalOverlap。

修复后先在实际选区内估计位移；选区内不动时直接维持原结果。小选区快速滚动、剩余重叠不足以独立估计时，仍允许使用外围画面推断距离，但必须在选区内验证剩余重叠，避免拼入无关移动。最终输出仍只包含裁剪后的选区。

自动回归覆盖：

- 大面积静止外围中，选区内连续向下及反向滚动；逐行验证输出像素。
- 选区静止而外围移动，结果保持不变。
- 横向选区滚动，逐像素验证输出。
- 外围推断的位移与选区不一致时拒绝该帧，保留已有结果。
- 保留原有小选区快速滚动测试：80 px 高选区滚动 70 px，外围帮助判断，剩余 10 px 重叠匹配后继续拼接。
- Swift CGImage 经 UniFFI 调用共享 Rust 核心的选区滚动回归。

本地 capture-core 的 140 项测试通过。完整原生构建结果记录于 PR；以下 GUI 项仍待实机验证。

| 场景 | 操作与预期 | 状态 |
|---|---|---|
| 内部滚动 | 选中网页内的 overflow 容器、编辑器或聊天列表，保持外围不动；慢速及中速滚动后截图持续增长，无重复接缝 | 待实测 |
| 页面滚动 | 普通网页内框选小区域，滚动整页，确认原有页面滚动拼接保持正常 | 待实测 |
| 反向与横向 | 回滚到已有内容不重复；继续超过原起点时补齐；横向滚动列顺序正确 | 待实测 |
| 不相关移动 | 保持选区内容静止，移动外围页面或播放外围动画，结果不增长 | 待实测 |
| 快速滚动 | 相邻帧保留重叠时可恢复匹配；完全无重叠时不强行拼接，已有结果仍可保存 | 待实测 |

本修复不改变滚轮事件传递。选区包含大量固定工具栏或内容完全跳过可匹配重叠时，仍受原有匹配条件限制。
