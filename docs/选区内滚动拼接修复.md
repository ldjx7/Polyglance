# 选区内部滚动无法拼接

基于 v0.1.5-beta.2。用户确认选区内内容实际已经滚动，但长截图没有继续增长。

macOS 为小选区向上下额外采集最多 400 pt 的画面，帮助判断快速滚动的距离。旧算法对整个采集帧估计位移。如果选区是页面中的独立滚动容器，外围画面保持静止，外围像素就会干扰选区内容的匹配。两项回归用例在旧实现中均返回 NoReliableVerticalOverlap。

修复后先在实际选区内估计位移；选区内不动时直接维持原结果。小选区快速滚动、剩余重叠不足以独立估计时，仍允许使用外围画面推断距离，但必须在选区内验证剩余重叠，避免拼入无关移动。最终输出仍只包含裁剪后的选区。

微信聊天反馈的进一步修复：

- 从选区自身边缘识别固定标题、输入区和侧栏。原先从完整采集帧边缘扫描，外围采集区域会先耗尽扫描范围，漏掉选区内的固定区域；聊天气泡样例在上一版返回无法匹配重叠。
- 慢速滚动时，新内容可能尚未超出初始图片的高度，但已经逐段替换固定顶部或底部。现在每次滚动都保留这些新露出的片段，避免后续增长时缺行。
- 已识别的聊天正文不动、仅输入区光标闪烁时保持结果不变。临时缩小后的匹配范围无法判定时，继续使用完整选区判断。
- macOS 按首帧的实际像素尺寸换算选区裁剪边界，避免缩放显示器上采集尺寸与请求尺寸不一致时使用错误裁剪范围；预览视口同步使用实际尺寸。

自动回归覆盖：

- 大面积静止外围中，选区内连续向下及反向滚动；逐行验证输出像素。
- 选区静止而外围移动，结果保持不变；包含小于常规匹配重叠要求的选区，以及滚动后停止的情况。
- 横向选区滚动，逐像素验证输出。
- 外围推断的位移与选区不一致时拒绝该帧，保留已有结果。
- 保留原有小选区快速滚动测试：80 px 高选区滚动 70 px，外围帮助判断，剩余 10 px 重叠匹配后继续拼接。
- 选区内包含固定标题、输入区及稀疏聊天气泡；慢速向上、向下滚动后逐像素比对完整结果，检查新露出的行没有丢失。
- 聊天区静止时输入区光标闪烁，包含曾经滚动后的情况；不误拼接。
- Swift CGImage 经 UniFFI 调用共享 Rust 核心的选区滚动回归，以及实际帧分辨率与请求分辨率不同的会话回归。

自动化测试及完整原生构建结果记录于 PR；以下 GUI 项仍待实机验证。

| 场景 | 操作与预期 | 状态 |
|---|---|---|
| 内部滚动 | 选中网页内的 overflow 容器、编辑器或聊天列表，保持外围不动；慢速及中速滚动后截图持续增长，无重复接缝 | 待实测 |
| 微信聊天 | 分别只选择聊天内容、连同固定顶部和底部输入区选择；慢速向上查看历史，再向下滚动；停止时输入区光标闪烁不增加截图高度，内容逐段完整 | 待实测 |
| 缩放显示 | 在默认及缩放分辨率下重复选区滚动，输出边界与所选区域一致，预览视口尺寸正确 | 待实测 |
| 页面滚动 | 普通网页内框选小区域，滚动整页，确认原有页面滚动拼接保持正常 | 待实测 |
| 反向与横向 | 回滚到已有内容不重复；继续超过原起点时补齐；横向滚动列顺序正确 | 待实测 |
| 不相关移动 | 保持选区内容静止，移动外围页面或播放外围动画，结果不增长 | 待实测 |
| 快速滚动 | 相邻帧保留重叠时可恢复匹配；完全无重叠时不强行拼接，已有结果仍可保存 | 待实测 |

本修复不改变滚轮事件传递。相邻画面完全跳过可匹配重叠、聊天内容在两帧之间被重排，或画面缺少可区分内容时，仍可能无法可靠拼接。合成聊天样例用于验证算法，不能替代微信实机验收。
