# ==============================================================================
# Polyglance - macOS 首次启动提示已损坏或无法打开的解决指南
# ==============================================================================
#
# 【为什么 macOS 会阻拦？】
# Polyglance 是一款 100% 透明开源的免费效率工具，未向 Apple 购买每年 99 美元的开发者
# 商业证书与公证。macOS Gatekeeper 安全机制会对从网络下载的未公证应用标记隔离属性，
# 提示「已损坏，打不开。你应该将它移到废纸篓」或「来自身份不明的开发者」。
# 本软件源码在 GitHub 完全透明公开，绝无任何恶意代码，请放心解除阻拦。
#
# ------------------------------------------------------------------------------
# 【方法一：在系统设置中放行（图形界面推荐）】
# 1. 关闭警告弹窗：点击弹窗中的「完成」或「取消」（切勿点击「移到废纸篓」）。
# 2. 打开隐私设置：点击屏幕左上角  菜单 >「系统设置」> 左侧边栏选择「隐私与安全性」。
# 3. 点击仍要打开：在右侧「安全性」区域找到「已阻止使用 Polyglance...」，
#    点击旁边的「仍要打开」(Open Anyway) 并输入密码或触控 ID 确认，随后点击「打开」即可。
#
# ------------------------------------------------------------------------------
# 【方法二：访达快捷右键打开（更快速）】
# 1. 打开「访达」(Finder)，进入「应用程序」(Applications) 文件夹。
# 2. 找到 Polyglance，按住键盘上的 Control 键并点击它（或鼠标右键点击）。
# 3. 在弹出的上下文菜单中点击「打开」。
# 4. 弹出的确认对话框中会直接显示「打开」按钮，点击即可正常运行并永久加入白名单。
#
# ------------------------------------------------------------------------------
# 【方法三：终端执行命令移除隔离属性（一键解决已损坏提示）】
# 确保已先将 Polyglance.app 拖入「应用程序」文件夹。
# 在本文件中按 Command+A 全选、Command+C 复制；打开「终端」(Terminal) 粘贴并按回车。
# 下方两行命令仅移除 Polyglance 的下载隔离标记并启动应用，不会关闭 Gatekeeper 或影响其他软件：
# ==============================================================================
/usr/bin/xattr -dr com.apple.quarantine "/Applications/Polyglance.app"
/usr/bin/open "/Applications/Polyglance.app"
